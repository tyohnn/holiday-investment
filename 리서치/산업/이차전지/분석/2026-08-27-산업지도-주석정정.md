# 산업지도 주석정정 — QC 재조회 (2026-08-27)

QC 서브에이전트 산출. 교재 미사용, 하위 에이전트 미사용, 지어낸 값 없음.
소스: 원격 Supabase `kglymnsytrenlbodmbid`, `financial_facts.sj_div='NOTE'`(주석 정본),
`fin_details`(concept: segment_revenue, market_share). reprt_code=11011(연간), 2023A~2025A.
투자 자문 아님 — 방법론 연습.

## 1. 한계 정정

- **`filing_sections` ≠ 주석 정본.** 이 파일의 원 지시(사용자 표 502/125,056)는 직전 스냅샷이다.
  이번 세션 원격 실측(감독 SQL 재조회): `financial_facts` 중 `sj_div='NOTE'` **126,969행 · 503개사**
  (지시문의 504사/126,396행과도 다름 — 증분 적재가 진행형이라 스냅샷마다 숫자가 바뀐다. 시점: 이 QC 실행).
  `fin_details`는 **574개사**(전 concept 합산, 회사당 concept 커버리지는 회사마다 다름).
- **`filing_sections`는 주석이 아니다.** 원격 `filing_sections` **1,427행**이며 전부 삼성전자 1개사
  귀속(AGENTS.md 2026-08-27 QC로그에 이미 잠긴 사실, 이번 세션 행수 재확인만 함). 이 7개사는
  `filing_sections`에서 애초에 조회 대상이 아니다 — 주석은 반드시 `financial_facts.sj_div='NOTE'`로 읽는다.
- **NOTE는 재무제표 부속 각주 항목 나열이지, 매출·시장점유율 원장이 아니다.** 계정명이 회사·연도마다
  달라 자동 매핑이 불가능하다(감가상각비를 "비용의 성격별 분류"에 싣는 회사도, "판매비와관리비"에만
  싣는 회사도 있다). 표는 **7개사 각각에서 실제로 존재한 계정명 그대로** 옮겼다.
- **2025A NOTE 절반이 자릿수 오염이다.** 세방전지·롯데에너지머티리얼즈·삼아알미늄·삼성SDI 4개사의
  2025A NOTE 전 행이 전년 대비 정확히 1000배 부풀려져 있다(§4). 코스모화학·포스코퓨처엠·비츠로셀
  2025A는 오염 없이 정상 자릿수였다 — **오염은 DB 전역이 아니라 특정 4개사 특정 연도 로딩분에 국한된다.**

## 4. 확인 불가

### 4-1. 단위 오염 — 2025A NOTE 전 행 폐기 (4개사)

판정 근거: 해당 2025A 행의 `amount_prev`가 전년(2024A) 확정 공시치의 **정확히 1000배**와 일치한다
(우연한 자릿수 근접이 아니라 정수배 일치 — 로딩 단계 단위 변환 버그로 판단).

| 회사 | 예시 계정 | 2024A 실측(원) | 2025A 행의 amount_prev(원) | 배율 |
|---|---|---|---|---|
| 삼성SDI(006400) | 감가상각비 | 1,772,839,439,000 | 1,772,839,439,000,000 | ×1000 |
| 세방전지(004490) | 이자수익(금융수익) | 14,015,479,000 | 14,015,479,000,000 | ×1000 |
| 롯데에너지머티리얼즈(020150) | 급여 | 19,773,552,000 | 19,773,552,000,000 | ×1000 |
| 삼아알미늄(006110) | 기타판매비와관리비 | 1,522,275,000 | 1,522,275,000,000 | ×1000 |

→ 이 4개사의 **2025A `financial_facts` NOTE 전 계정(amount·amount_prev 둘 다) 폐기**. 삼성SDI 2025A
감가상각비가 "2,009조"로 찍힌 게 바로 이 오염의 예시(사용자 지시에 이미 명시된 판정 기준과 일치).
비츠로셀·코스모화학·포스코퓨처엠 2025A는 동일 검증(전년 대비 자릿수)에서 **오염 없음** — 표3에
그대로 사용.

### 4-2. 그 외 개별 이상치

- **삼성SDI 2023A NOTE "이자수익(금융수익)" = −82,954,221,000,000원(−82.9조)**: 계정명·부호·규모가
  모두 비정상(이자수익이 마이너스 82조는 SDI 연간 매출 규모를 넘어섬). 단위 오염 4개사 목록에는
  없는 연도지만 이 한 행만 별도로 오염·오분류로 판단해 폐기. 원인 미상.
- **롯데에너지머티리얼즈 "건설부문" 세그먼트**: 2차전지 소재(동박) 회사에 왜 건설 세그먼트가
  있는지 원문(사업보고서 세그먼트 주석)을 이번 세션에서 직접 열람하지 않아 확인 불가. 연결 자회사
  중 건설업 법인이 있을 가능성으로 **추정**만 해둔다.
- **삼아알미늄 "전자부품판매"가 2차전지용 알루미늄박인지**: 품명 상세가 원문에 없어 확인 불가.
- **market_share 없음(fin_details)**: 롯데에너지머티리얼즈·삼아알미늄·비츠로셀·코스모화학·
  포스코퓨처엠 5개사 전부. `fin_details`에 이 5개사의 시장점유율 concept 행 자체가 없다 — 미공시가
  아니라 이 파이프라인이 아직 추출하지 못했을 가능성 둘 다 열려 있다(구분 불가).
- **segment_revenue 없음(fin_details)**: 비츠로셀·코스모화학·포스코퓨처엠 3개사. 위와 동일한 사유로
  구분 불가.
- **세방전지 "EV전지" 세그먼트의 정확한 제품 정의**: 원문에 화학 성분·전압 규격 표기가 없어
  12V 보조배터리인지 다른 규격인지 확인 불가. "리튬 트랙션셀이 아니다"까지만 확신 가능(세방전지는
  리튬 셀 생산 이력 자체가 공개돼 있지 않음 — 이 데이터셋 기준).
- **NOTE 계정 커버리지의 회사·연도 편차**: 같은 회사도 연도마다 주석에 싣는 계정이 다르다(예:
  포스코퓨처엠 2023A는 감가상각비 행이 없고 현금흐름 조정 항목만 있음). 시계열 결측이 실제 값
  0이나 비공개를 뜻하지 않는다 — 단순히 해당 연도 주석에 그 계정이 없다는 뜻.
