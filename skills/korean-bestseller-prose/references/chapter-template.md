# 통합 장 템플릿 (12운동)

모델: *더 골* (발견 나선) + *부의 추월차선* (대조·구분법) + *마케팅 설계자* (도식·스크립트) + *타이탄의 도구들* (사례 패킷·교차참조).  
보조: *Made to Stick* (단순·의외·구체·신뢰·감정·이야기), *Storyworthy* (변화의 짧은 순간), *On Writing Well* (리드=훅).

한 장 전체를 다시 쓸 때만 12개를 모두 쓴다. 도입부만이면 1–3, 사례 절이면 4–9.

## 1. 비용이 큰 순간으로 연다

200–400자. 행동·문서·숫자 모순. 교훈 선언 금지.  
예: 영업이익은 늘었는데 현금은 줄었다 / 주차장이 점령된 공장장(*더 골*).

## 2. 주인공과 이전 믿음

독자도 가질 법한 믿음을 정직하게. 사후 비웃지 말 것.  
짧은 케이스 여권: 날짜·회사·당시 알 수 있던 정보·결정·결과.

## 3. 지배 질문

독자가 먼저 답해볼 질문 하나.  
「매출이 40% 늘었는데 왜 현금이 줄었나?」

## 4. 처음 보이는 답

관행·초보 모델을 정직하게 굴려 잘못된 결론까지.  
*Fastlane*의 대조 구조. 섹션 제목 예: 「처음 보이는 답」.

## 5. 발견

단서 → 독자 예측 → 계산/검증 → 모순.  
일상 비유는 *더 골*의 하이킹처럼 **이름보다 먼저**.

## 6. 이름표

이해 뒤에만: 「이것을 **현금전환주기**라고 부른다.」  
한국어 일상 정의 → (필요 시) 영어 용어. 약어는 이미 이해한 내용의 압축일 때만.

## 7. 한 장짜리 모델

기억에서 다시 그릴 수 있는 도식·식·의사결정 나무 하나.  
필수 주석: 입력 / 인과 방향 / 결정점 / 실패 조건. (*마케팅 설계자*의 이미지 리콜)

## 8. 증거 사다리

| 등급 | 역할 |
|---|---|
| 사례 | 가능성 |
| 비교 사례 | 경계 |
| 통계·연구 | 빈도·크기 |
| 해석 | 저자 결론 (명시) |

설득력 있는 일화가 증거를 **대체**하지 못하게 한다.

## 9. 합병증

규칙이 깨지거나 기계 적용이 새 문제를 만드는 경우.  
*더 골*의 2차 효과. 슬로건화를 막는다.

## 10. 스케일 전이

한 계정 줄 → 회사/산업 → 포트폴리오 결정.  
교차 참조는 *Titans*식으로 「같은 규칙, 다른 행동」.

## 11. 판단 스크립트

5–7개 **동사** 질문 + 자료 출처 + 무효화 조건 + 행동.  
목차형(「산업 분석」) 금지. 「최근 3년 가격·물량 분리」 OK.

## 12. 구분법 + 열린 고리

장말 3–5개 「투자 구분법」(*Fastlane Distinctions* 변용).  
부분 완결 + 다음 장의 **구체 변수**. 「충격적 진실」낚시 금지.

## 독자가 장 끝에 남겨야 할 네 기억

1. 인간적 장면  
2. 이름 붙은 원리  
3. 간단한 그림  
4. 재사용 가능한 절차
