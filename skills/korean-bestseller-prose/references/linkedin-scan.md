# 모드: linkedin-scan — 스캔 가능하되 책답게

「링크드인 스타일」= **주의·항해 레이어**이지 완성된 문학 형식이 아니다.  
가져올 것: 즉시 요점, 짧은 문단, 정보성 첫 문장, 인간적 판단.  
버릴 것: 바이럴 미끼, 이모지 장식, 가짜 취약성, 매 문장 한 줄 개행.

근거: LinkedIn/Edelman thought leadership, NN/g inverted pyramid·scannable, Microsoft style guide, 한글 줄길이 연구(줄≠문단). 상세는 리서치 리포트.

## 규칙

1. **가치부터** 연다. 주제 숨기는 가짜 「더 보기」 금지.
2. 장마다 **논쟁 가능한 약속** 하나. 「리더십의 중요성」 같은 공허 금지.
3. **한 아이디어/문단.** 기본 1–3문장. 한 문장 문단은 전환·결론에만.
4. **80–140자**는 진단용 휴리스틱이지 법률이 아니다.  
   - 대개 70–160자(공백 포함)  
   - ~40자 미만은 진짜 강조일 때만  
   - ~220자 넘으면 숨은 두 번째 아이디어 검사
5. 문단 **첫 문장이 정보**를 운반. 「이와 같은 맥락에서…」 삭제.
6. 이야기는 **상황–마찰–선택–결과–해석**. 검증된 마찰만. 가짜 드라마 금지.
7. 취약성은 **메커니즘을 밝힐 때만** (감정 전시 금지).
8. 훅 직후 **증거**. 「데이터는 / 시사 / 이 사례에서는 / 가설」을 구분.
9. 인간적 목소리 = 소유된 판단. 수다·슬랭 강제 금지.
10. 리듬 **변주**. 전 원고를 한 줄 문단으로 쓰지 말 것.
11. 헤더는 **약속/주장**. 「배경」「인사이트」 금지. 불릿은 병렬 항목에만.
12. 끝은 **결과·적용·다음 장 다리**. 「여러분은 어떻게 생각하나요?」 금지.

## 스캔 테스트

제목 + 소제목 + 각 문단 첫 문장만 읽었을 때 **요약이 성립**해야 한다.

## 교재 기본 골격

답/장면 훅 → 장 약속 → 2–4절(주장·증거·메커니즘·한계) → 반례 → 적용 1개 → 다음 장 다리.
