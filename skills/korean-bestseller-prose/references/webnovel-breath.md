# 모드: webnovel-breath — 웹소설 호흡 (교재 전용)

가져올 것: 호기심 → 이해 → 적용 → 새 궁금증.  
가져오지 말 것: 자극적 절단 남발, 「문단=무조건 3줄」 미신, 가짜 대사.

근거: 최배은 웹소설 서술형식 연구(KCI), 한콘진 웹소설 정책연구, 문피아/노벨피아 분량 규정, 작가·PD 실무 인터뷰. 상세는 리서치 리포트.

## 핵심 리듬

**사건 → 긴장(이해관계) → 정보 → 사례 복귀 → 작은 판정**

1. 사건: 예상과 어긋난 숫자/공시
2. 긴장: 이 숫자를 놓치면 생기는 오판
3. 정보: 지금 사례를 한 단계 해석할 개념만
4. 복귀: 처음 수수께끼에 적용
5. 판정: 눈에 보이는 작은 진전

## 규칙

1. 한 장 = 하나의 **독자 약속** (「이익이 늘어도 망할 회사 고른다」).
2. 정의가 아니라 **이상 현상**으로 시작.
3. 한 문장 = 한 인지 작업.
4. 한 문단 = 한 논리 동작 (문제/증거/원인/판정).
5. 단문만 반복하지 말고 **호흡 변주**.
6. 정보는 **필요해진 순간**에만 출시 (정확성 필수 정의는 숨기지 말 것).
7. 절마다 작은 보상 (사실·도구·오해 교정·체크·판정 중 하나).
8. 장 끝 = **부분 완결 + 열린 판단** (구체 변수).
9. 클리프는 **약속**이며 다음 절 초반에 **상환**. 「충격적 진실」 금지.
10. 대화 기능은 질문·실제 발언·쟁점으로. 가짜 CEO 대사 금지.
11. 고급스러움 = 어려운 말 ≠ **정밀도** (기업·기간·기준값·사실/해석 구분).
12. 가능하면 **모바일 폭**으로 첫 화면·검은 덩어리·과도한 강조를 점검.

## 싸구려 vs 프리미엄

| 싸구려 | 프리미엄 |
|---|---|
| 모든 숫자를 「폭발적」 | 기준값·기간 명시 |
| 문단마다 반전 선언 | 반전은 드물고 회수됨 |
| 한 문장씩 개행 남발 | 논리 단위로 개행 |
| 약속 미상환 | 연독 신뢰 = 상환 습관 |

## 교재용 미니 골격

사건 → 판단 질문 → 개념 2–3묶음(각 묶음 후 사례 적용) → 부분 보상 → 다음 고리.
