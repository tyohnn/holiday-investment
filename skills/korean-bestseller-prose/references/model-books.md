# 모델 책 구조 메모

에이전트는 이 네 권의 **구조**만 빌린다. 투자·마케팅 결론을 그대로 옮기지 않는다.

## 더 골 — Eliyahu Goldratt & Jeff Cox

- 형식: 비즈니스 소설. 위기 → 소크라테스 질문 → 비유(하이킹) → 실험 → 부작용 → 5단계 이름.
- 도입: in medias res (주차장·독촉 주문).
- 빌릴 것: 발견 나선, 용어 지연, 일상 비유가 이론보다 앞섬.
- 교정: 숫자는 표·출처로 감사 가능하게.

## 부의 추월차선 — M. J. DeMarco

- 형식: 로드맵 은유(Sidewalk / Slowlane / Fastlane), 8부 45장, 장말 Distinctions.
- 도입: 에피그래프 → 일화 → 은유 해석 → 이름 붙은 구분.
- 빌릴 것: 잘못된 길 대조, 장말 구분법, 일상어→라벨(CENTS 등).
- 교정: 공격적 캐리커처·주식 비하 결론은 이식 금지. 구조만.

## 마케팅 설계자 — 러셀 브런슨 (*DotCom Secrets*, 윌북 2022)

- 한국어 정식: 『마케팅 설계자: 자동 수익을 실현하는 28가지 마케팅 과학』.
- 형식: Secret 0 + 28 secrets. 공식 이해 → 퍼널 설계 → 스크립트 → 완성·반복.
- 도입: Hook–Story–Offer. 맥도날드 업셀·치과 Value Ladder처럼 **고객 경험 후 이름**.
- 빌릴 것: 도식 리콜, 스크립트(질문 절차), 원리→변형→언어→구현.
- 교정: 창업 과장·매출 일화의 증거 등급을 투자 데이터로 교체.

## 타이탄의 도구들 — Tim Ferriss

- 형식: Healthy / Wealthy / Wise. 프로필 패킷 + 교차 참조. 뷔페·레퍼런스.
- 도입: 압축된 권위+이상함. 「이 사람은 왜 이런 결과를?」
- 빌릴 것: 짧은 전술, 인물/사례 컨테이너, 장 간 링크.
- 교정: 생존자 편향 표시, 장말 합성(인과 vs 상관) 필수.

## 책 전체 권장 아키텍처 (교재용)

1. **지도를 바꾼다** — 목표·증거·잘못된 지도 (*Fastlane* 해체)  
2. **기계를 해부한다** — 발견 사례 (*Goal*)  
3. **가격·위험을 결정으로** — 도식+스크립트 (*마케팅 설계자*)  
4. **도구함** — 프로필·체크·교차참조 (*Titans*, 비선형 재사용)
