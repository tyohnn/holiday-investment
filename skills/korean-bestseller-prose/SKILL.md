# korean-bestseller-prose — 베스트셀러형 한글 논픽션 작법

## 언제 쓰는가

- 투자·경영·역사 교재/아티클을 **읽히게** 개작할 때
- 도입부를 **장면**으로 열되, 허구를 만들지 않을 때
- 문단 호흡을 **웹소설·링크드인**처럼 짧게 하되, 싸구려 클리프·바이럴 티를 피할 때
- 개념을 **일상어 → 이름표** 순서로 심을 때

**하지 않는 일:** AI 티만 기계적으로 치환하는 단순 윤문(그건 humanize 계열). 가짜 수치·가짜 대사·강의에 없는 사실 추가.

## 모델 책에서 가져올 것 / 버릴 것

| 책 | 가져올 구조 | 버리거나 교정할 것 |
|---|---|---|
| **더 골** | 위기 장면 → 가설 → 실험 → 부작용 → 늦게 이름 붙이기 | 숫자 감사 추적 없는 순수 우화 |
| **부의 추월차선** | 대조 지도(잘못된 길 vs 대안) + 장말 「구분법」요약 | 공격적 캐리커처·투자 결론 그대로 이식 |
| **마케팅 설계자** (*DotCom Secrets*) | Hook–Story–Offer, 도식 → 스크립트 → 검증 | 마케팅 과장·창업 일화의 증거 등급 |
| **타이탄의 도구들** | 인물/사례 패킷, 짧은 전술, 교차 참조 | 생존자 편향 방치·합성 부재 |

공통 법칙:

> **구체 경험이 추상의 필요를 만들고, 이름은 이해를 압축하며, 도구는 이해를 전이시킨다.**

세부 구조: `references/model-books.md`, `references/chapter-template.md`

## 모드 선택 (작업 전 1개 이상)

요청에 맞춰 모드를 고른다. 교재 기본값은 `nonfiction + webnovel-breath + linkedin-scan`이고, 장 도입부만 손볼 때는 `novel-opening`을 추가한다.

| 모드 | 파일 | 핵심 |
|---|---|---|
| `novel-opening` | `references/novel-opening.md` | 이미 달라진 순간에서 시작, 행동 카탈로그 금지, 감각 1~2개 |
| `webnovel-breath` | `references/webnovel-breath.md` | 사건→긴장→정보, 한 문단=한 논리, 약속 상환 |
| `linkedin-scan` | `references/linkedin-scan.md` | 짧은 문단·정보성 첫 문장, 바이럴 미끼 금지 |
| `nonfiction` | `references/nonfiction-evidence.md` | 장면→원리→반례→적용, 사실/추론 구분 |
| `anti-patterns` | `references/anti-patterns.md` | 「이 자리에서」, 강제 `~을수록`, 추상 은유 군집 등 |

## 절대 보존

- 사실·수치·날짜·고유명사·인용문
- 위키링크 `[[파일|N장 제목]]`, `<!-- MEDIA -->`, `## 직접 해보기`, `## 핵심 요약`
- 강의/원문에 없는 새 사례·가짜 티커·가짜 주가 금지
- 논픽션에서 기록 없는 대사·표정·날씨 **창작 금지** (Poynter: do not add, do not deceive)
- 가상 시나리오면 **"가상 사례"** 명시

프로젝트에 `교재/_집필스타일.md` 또는 `textbook-plan/REWRITE-GUIDE.md`가 있으면 **함께** 따른다. 충돌 시: 사실 보존 > 프로젝트 가이드 > 이 스킬의 문체 권고.

## 작업 절차

1. **범위** — 파일/절, 모드, 분량 목표(원문 85~115%)를 정한다.
2. **장 약속** — 한 문장: 「이 장을 읽으면 독자는 ___을 판별/실행할 수 있다.」
3. **골격** — `references/chapter-template.md`의 12운동 중 해당 구간만 적용한다. (도입만이면 1~3, 본문 사례면 4~9, 마무리면 10~12)
4. **초고 개작** — 모드 파일을 순서대로 적용. 문단을 쪼개되 논증을 불릿으로 해체하지 않는다.
5. **이름표** — 개념은 장면/비교로 이해시킨 **뒤** 「이것을 X라고 부른다」.
6. **자기검증** — 아래 체크리스트. 실패 항목만 재수정.
7. **보고** — 바꾼 호흡/구조 포인트 5줄 + 사실 보존 확인 + 남은 리스크.

## 장 골격 (요약)

상세는 `references/chapter-template.md`.

1. 비용이 큰 **순간**으로 연다 (정의 강의 금지)
2. 주인공의 **그럴듯한 이전 믿음**
3. 독자가 먼저 답해볼 **지배 질문**
4. **처음 보이는 답**(오해/관행)을 정직하게 굴린다
5. 단서 → 예측 → 검증 → 모순 (**발견**)
6. 그제야 **이름**을 붙인다
7. **한 장짜리 도식**/식/의사결정 나무
8. **증거 사다리** (사례 / 비교 / 통계·연구 / 해석 — 등급 표시)
9. **합병증·반례** (규칙이 깨지는 조건)
10. 재무·회사·포트폴리오 등 **스케일 전이**
11. 5~7문항 **판단 스크립트**(동사형)
12. 「구분법」요약 + 다음 장으로 가는 **열린 고리**(낚시 금지)

## 문장·호흡 빠른 규칙

- 한 문장 = 한 인지 작업. 사실·원인·평가·예외를 한 줄에 몰지 말 것.
- 한 문단 = 문제 / 증거 / 원인 / 판정 중 **하나**.
- 짧은 문장(전환·결론)과 중간 문장(인과)을 섞는다. 전보문 `~다. ~다. ~다.` 동작 나열 금지.
- 연결은 어미·마침표로. 영어식 쉼표 연쇄 남발 금지.
- `값어치` → `가치`. 번역투(`~를 통해`, `~에 대해`, 이중 피동) 최소화.
- 헤더는 내용어 주장형. `## 배경`, `## 인사이트` 금지.

## 자기검증 체크리스트

- [ ] 첫 화면/첫 문단에 **좌표**(누가·무엇·무엇이 어긋났나)가 있는가
- [ ] 행동 카탈로그(연속 동작 3+)나 「한다 한다」 나열이 없는가
- [ ] 「이 자리에서」「바로 그 순간」 등 **장소 관용구를 상황 대용어로** 쓰지 않았는가
- [ ] `~을수록`이 **실제 비례**일 때만 쓰였는가
- [ ] 추상 은유(침묵의 심장, 변화의 파도…)가 군집하지 않는가
- [ ] 개념 이름이 **설명 뒤**에 왔는가
- [ ] 사례가 주장의 **증거**이고, 가능하면 **경계/반례**가 있는가
- [ ] 장/절 끝 약속이 **다음 절에서 상환**되는가
- [ ] 링크드인식 「공감하면 공유」·이모지 장식·가짜 취약성이 없는가
- [ ] 수치·링크·표·MEDIA·직접 해보기·핵심 요약이 보존됐는가

## 출력 형식

같은 경로에 덮어쓰거나, 사용자가 지정한 경로에 저장한다. 변경 요약은 짧게:

```
모드: …
장 약속: …
구조 손질: …
문장/호흡: …
보존 확인: 수치·링크·표 OK / 이슈 …
```
