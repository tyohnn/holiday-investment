# 사실 시계열(트래킹) 문서 — 작성 규칙

> 사업보고서는 **횡단면 스냅샷**이다. 한 해치를 아무리 정독해도 "작년 대비 무엇이 달라졌는가"는
> 보이지 않는다. 투자 판단에 필요한 건 **종단면 변화**이고, 그것을 만드는 것이 이 문서다.
> 여러 자료(사업보고서 주석·공시·IR·뉴스)에서 한 주제에 관한 사실만 뽑아 시간순으로 쌓는다.

## 위치와 계층

```
리서치/기업/<종목>/
├── 자료/      raw — 수집한 그대로, 해석 없이
├── 트래킹/    ← 여기. 여러 자료에서 추출·정렬한 사실 시계열 (해석 아님)
├── 계산/      스크립트 입출력
└── 분석/      판단 — 리포트
```

트래킹은 자료와 분석의 중간층이다. **사실만 담되 출처가 붙고, 해석은 넣지 않는다.**
판단("따라서 저평가다")은 분석 리포트의 몫이다.

파일명은 날짜 없이 주제로 짓는다 — 계속 갱신되기 때문이다: `트래킹/자사주-매입과-소각.md`

## 형식

```markdown
---
주제: 자사주 매입과 소각
종목: 크래프톤
최초작성: 2026-07-24
최종갱신: 2026-07-24
---

# 자사주 매입과 소각

| 시점 | 사실 | 수치 | 출처 |
|---|---|---|---|
| 2025-02-11 | 자기주식 취득 신탁계약 체결 | 1,000억 원 | 주요사항보고서 (20250211000456) |
| 2025-08-14 | 취득 완료, 전량 소각 결정 | 34.2만 주 (발행주식의 0.7%) | 주요사항보고서 |
| 2026-02-10 | 2차 취득 결정 | 2,000억 원 | 주요사항보고서 |
| 2026-05-15 | 1차 취득분 소각 완료 | 발행주식수 4,894만 → 4,860만 주 | 사업보고서 2025.12 §VII |
```

규칙:

- **시간 오름차순** (오래된 것 → 최신). 읽으면 변화가 이야기로 읽힌다.
- **줄은 추가만 한다. 기존 줄을 고치지 않는다.** 사실은 불변이고, 나중에 정정되면
  "정정됐다"는 사실을 새 줄로 추가한다(기재정정 감지도 같은 방식으로 한 줄이 된다).
- **출처 필수** — 어느 보고서·공시·주석에서 나왔는지. 접수번호가 있으면 함께.
- **수치는 별도 열**로 뽑는다. 나중에 대시보드가 그래프로 그릴 수 있고, 스캔이 쉽다.
- 사실이 서술형이라 수치 열이 비면 `—`.
- **해석·전망·평가어를 쓰지 않는다.** "긍정적이다", "우려된다" 같은 말이 들어가면 그건
  분석 리포트로 옮긴다.

## 기본 주제 세트

아래는 방법론이 실제로 추적을 요구하는 것들이다. 해당 사항이 있는 주제만 만든다
(빈 문서를 만들지 않는다). 종목 고유 주제는 자유롭게 추가한다.

| 주제 | 추적 내용 | 방법론 근거 |
|---|---|---|
| `자금조달-지분희석` | 유증·CB·BW 발행 → 전환청구 → 잔액, 오버행 물량 | I1 지분 희석 |
| `캐파-투자집행` | 증설 발표 → 착공 → 가동, CAPEX 집행률, 일정 변경 | C3 확정분만 반영 |
| `수주-계약` | 대형 계약 체결 → 물량 투입 시기 → 실제 매출화 | B4 피셔 팩트 추적 |
| `제품-파이프라인` | 신제품 발표 → 출시 → 성과 (게임=신작, 제조=신제품) | B4 매수 타이밍 3단계 |
| `지분-지배구조` | 오너 지분 변동, 자사주 취득·소각, 대량보유 신고 | B4 내부자 매수 판독 |
| `이익률-구조` | 부문별 이익률 추이, 원자재·판가, 믹스 변화 | B3 이익률 3층 |
| `소송-규제-우발부채` | 소송 제기 → 진행 → 결과, 규제 변화, 지급보증 | D1 주석 체크 |
| `경영진-핵심인재` | CEO·핵심 임원 교체, 개발 인력 이탈, 조직 개편 | B4 문화 3신호 |

이 세트는 제조업 어휘로 쓰여 있다 — **업종에 맞게 번역해서 쓴다**:

| 업종 | 캐파-투자집행 → | 수주-계약 → |
|---|---|---|
| 게임·콘텐츠 | 제작 파이프라인·개발 투자·M&A (`투자집행-MA` 등) | 퍼블리싱 계약·계약부채·판호 |
| 바이오 | 생산설비·임상 파이프라인 | 기술이전(L/O)·마일스톤 |
| 플랫폼·SW | 인프라 투자·M&A | 대형 고객 계약·수주잔고(백로그) |

### 특히 값어치가 큰 것: `캐파-투자집행`

교재는 "회사별 사풍(부풀리는 회사 vs 보수적인 회사)을 보정해 읽어라"라고만 하고 넘어간다.
판정 기준이 감이었던 것인데, **발표한 계획과 실제 이행을 나란히 시간순으로 쌓으면 그 판정에
증거가 생긴다.** "2024년에 2026년 완공을 발표했고 실제로는 2027년에 됐다"가 두 줄로 남으면,
그 회사의 다음 가이던스를 얼마나 할인해서 읽을지가 데이터로 결정된다. 매출 추정(C3)의
정확도를 직접 끌어올리는 지점이다.

## 언제 만들고 언제 갱신하는가

**생성**: 심층 분석 중 사업보고서 주석·사업의 내용을 읽다가 장기 추적 가치가 있는 주제를
발견하면 만든다. 발견 즉시 만들고, 리포트에 "트래킹 문서 N건 생성"을 보고한다.
사용자가 특정 주제를 지목하면("이 채무 추적해줘") 그것도 만든다.

**갱신**: 분석을 시작할 때 `트래킹/` 목록과 각 문서의 최종갱신일을 먼저 확인한다.
이번에 수집한 새 자료(신규 공시·새 사업보고서·뉴스)에 해당 주제의 새 사실이 있으면
줄을 추가한다. 갱신 후 manifest의 `트래킹` 항목도 최신화한다.

**분석에서의 사용**: 트래킹 문서는 리포트의 근거가 된다. 특히
- 피셔 매수 타이밍 3단계 판정 → `제품-파이프라인`·`캐파-투자집행`
- 스토리 훼손 판정(F1 매도 트리거) → 해당 주제 문서의 최근 줄들
- 가이던스 신뢰도(사풍) → `캐파-투자집행`의 발표 vs 실제
- 지분 희석 리스크 → `자금조달-지분희석`의 잔액 추이

## 주의

- 사업보고서 섹션 md는 표 서식이 일부 손실된다. **수치를 트래킹에 옮길 때 원문 뷰어와
  대조**하고, 불확실하면 그 사실을 출처 열에 적는다.
- 한 문서가 너무 커지면(50줄 이상) 주제를 쪼갠다.
- 사실 여부가 불확실한 것(언론 추측·애널리스트 전망)은 넣지 않는다. 회사 발표·공시·
  실제 실적만 넣는다. 언론발이면 출처에 매체명을 명시한다.
