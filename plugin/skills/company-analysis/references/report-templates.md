# 리포트 템플릿과 저장 규칙

## 경로·파일명

```
리서치/기업/<종목명>/YYYY-MM-DD-기본분석.md
리서치/기업/<종목명>/YYYY-MM-DD-심층분석.md
```

- 현재 작업 디렉토리 기준. 폴더가 없으면 만든다.
- 같은 날짜·같은 종류 파일이 있으면 새 파일을 만들지 말고 기존 파일을 갱신한다.
- 리포트는 폴더 루트에만 둔다. raw 수집 자료는 `자료/`, assumptions/valuation JSON은
  `계산/` — 전체 규칙은 `data-layout.md`.
- frontmatter의 낙점적정주가·상승여력·진입가는 `scripts/valuation.py` 출력(valuation.json)
  값을 그대로 쓴다. 저장 후 `scripts/validate_report.py` 게이트를 통과해야 완성이다.

## Frontmatter 스펙 (대시보드 렌더링용 — 키 이름 고정)

```yaml
---
title: <종목명> <기본|심층>분석
종목: <종목명>
티커: "<6자리 코드 또는 해외 티커>"
시장: KOSPI | KOSDAQ | NYSE | NASDAQ | 기타
모드: 기본 | 심층
데이터기준일: YYYY-MM-DD
현재주가: <숫자>
시가총액: <숫자, 억원>
적정주가범위: [<9칸 최소>, <9칸 최대>]
낙점적정주가: <숫자>
상승여력: <낙점 기준 %, 소수 1자리>
진입가: <낙점 적정주가 ÷ 3>
안전마진충족: true | false
기업등급: A | B | C
피셔타이밍: "①기대감" | "②실적공백" | "③양산본격화"
요약: >-
  <3줄 스토리를 한 문단으로>
---
```

숫자를 확보하지 못한 필드는 null로 두고 본문에 "미확인" 사유를 쓴다.

## 기본 분석 골격

섹션 순서와 제목을 그대로 쓴다. 각 섹션이 답할 질문이 정해져 있다.

```markdown
# <종목명> 기본분석 (YYYY-MM-DD)

## 1. 요약
- 매수 이유 3줄 스토리 (또는 "보지 않는 이유" 3줄)
- 판정 한 문장: 안전마진 충족 여부 + 진입가 + 피셔 타이밍 단계
- 핵심 수치 표: 현재주가/시총/낙점 적정주가/상승여력/진입가 (기준일 병기)
- (과거 리포트가 있으면) 추정의 갱신: 무엇이 왜 달라졌는가 한 줄

## 2. 기업 개요와 능력범위
- 무엇으로 돈을 버는 회사인가 (사업부문·매출 비중)
- 능력범위 판별 2문 (사용자 자답용)

## 3. 1차 자료 체크
- 재무 추이 표: 매출·영업이익률·ROE·부채비율 3~4년 (출처·기준일)
- 수주·캐파·가동률 (바인딩만), 지배구조·자금조달 이력 (CB·유증)

## 4. 해자와 정성 점검
- 팻 도시 4유형 중 해당 유형과 증거, 가격결정권 판정 (세계 1등 여부)
- 피셔 핵심 2문에 대한 답
- 문화 3신호·내부자 매수 등 특이사항 (있는 것만)

## 5. 밸류에이션 — 3년 후 적정주가 5단계
- 가정 명시: 성장률 3케이스 근거, 영업이익률 근거, PER 3값 근거
- 단계별 계산 (표)
- 9칸 시나리오 매트릭스 (표, 각 칸에 적정주가와 상승여력)
- 낙점과 근거 (IR 로데이터 인용)
- 교차검증 (가이던스 정합·피어 PER·미래 PSR 중 1개 이상)

## 6. 주가의 3요소 진단
- 최근 주가 국면: 내재가치·외부 재료·시장 인식 중 무엇이 움직였나

## 7. 판정과 관찰 포인트
- 편입 3대 기준 점검, 기업 3분류 등급과 비중 상한
- 피셔 매수 타이밍 3단계 중 현재 위치
- 스토리 훼손 조건 (= 매도 트리거)
- 관찰 포인트: 지표·이벤트 목록 (다음 분석 때 갱신할 것들)

## 8. 출처
- 외부 자료 목록 (URL·문서명·기준일)

---
*이 문서는 가치투자 방법론(3년 후 적정주가 5단계)에 따른 학습·분석 자료이며 종목 추천·투자
권유가 아니다. 모든 수치는 데이터기준일 시점의 추정이고, 투자 판단과 책임은 각자의 몫이다.*
```

## 심층 분석 추가 골격

기본 골격의 4와 5 사이에 산업 파트를 넣고, 7에 팩트 추적을 확장한다.

```markdown
## 5. 산업 해부
- 경쟁력 축 (3~6개, 왜 이 축인가)
- 기업별 채점표 (상/중/하)와 종합 서열 — 서열 vs 시총 괴리 지점
- 산업 국면 3문: 시장규모(캐즘·침투율) / 점유율(분해) / 이익률(3층)
- 라이프사이클 판정 (5단계) 또는 버블/혁명 3대 기준 (신규 테마)

## 6. 밸류체인 지도
- 상류↔하류 지도와 대상 기업의 위치
- 돈 도는 순서(채찍효과)와 현재 사이클 위치
- 수주 연결고리 (고객사 → 물량 → 시기)

## 7. 밸류에이션 (기본 골격 5와 동일 + 아래)
- 경쟁사 상대가치 표 (실전 PER·PSR·시총 비교)
- 저평가 사다리 경로 (지주·우선주 있으면 계산)

## 9. 판정과 관찰 포인트 (기본 골격 7 + 아래)
- 팩트 추적 캘린더: 향후 12개월 확인 이벤트 (실적발표·양산·규제 일정)
```

## 문체 규칙

- 근거 제시형 "~다" 서술체. 주장 뒤에 반드시 숫자나 출처.
- 비유·수사·과장 없이 쓴다. 형용사 대신 숫자.
- 표는 숫자 비교용으로만, 설명은 본문 문장으로.
- 단위 명시: 조/억, 생산능력 단위, %(소수 1자리). 모든 시점 데이터에 기준일.
- 방법론 근거는 개념 이름으로 표기한다(예: "3년 후 적정주가 5단계", "피셔 매수 타이밍 3단계",
  "저평가 사다리"). 외부 파일 경로를 링크하지 않는다.
- 이모지·불릿 남발 금지. 섹션당 불릿은 필요한 만큼만.

## 저장 후

- 리포트 저장 경로를 사용자에게 알리고 핵심 결론(판정 문장)을 요약해 보여준다.
- `리서치/기업/<종목명>/`에 과거 분석이 있으면 변화(적정주가·낙점·판정의 이동)를 리포트
  1절에 한 줄로 언급한다 — 추정의 갱신 이력이 곧 실력이다.
