# 리서치 워크스페이스 레이아웃 — raw 자료와 분석의 분리

> 스킬이 프로젝트 폴더에서 실행될 때 생성하는 모든 파일의 위치 규칙이다.
> 원칙: **완성 리포트는 폴더 루트, raw 수집 자료는 `자료/`, 계산 중간산출물은 `계산/`.**
> raw 를 분리 보관하는 이유 — ①다음 분석이 재수집 없이 증분 갱신할 수 있고 ②리포트의
> 모든 숫자를 원자료로 역추적할 수 있으며 ③트래커(데일리 수집)가 같은 폴더에 쌓인다.

## 기업

```
리서치/기업/<종목명>/
├── YYYY-MM-DD-기본분석.md          # 완성 리포트 (루트 = 완성품만)
├── YYYY-MM-DD-심층분석.md
├── 자료/                           # raw 수집 자료 — 수집한 그대로, 해석 없이
│   ├── 시세/YYYY-MM-DD-시세.md          # 주가·시총·발행주식수 스냅샷 (출처 2개 교차)
│   ├── 재무/YYYY-MM-DD-재무추이.md      # 3~4년 매출·이익률·ROE·부채 표 (공시 발췌)
│   ├── 공시/YYYY-MM-DD-<제목>.md        # 사업보고서·수주·유증·CB 등 공시 발췌
│   ├── IR/YYYY-MM-DD-<제목>.md          # IR 자료·가이던스·컨콜 발췌
│   └── 뉴스/YYYY-MM-DD-뉴스클리핑.md    # 기사에서 취한 원데이터 (판매량·수출입 통계)
└── 계산/                           # 스크립트 입출력 — 재계산 가능해야 한다
    ├── YYYY-MM-DD-assumptions.json      # valuation.py 입력 (가정 전부)
    └── YYYY-MM-DD-valuation.json        # valuation.py 출력 (9칸·낙점·진입가)
```

## 산업

```
리서치/산업/<산업명>/
├── YYYY-MM-DD-산업분석.md
├── 자료/
│   ├── 시장규모/    # 침투율·수요 통계 (금액 기준)
│   ├── 점유율/      # 기업·국가별 점유율 로데이터 (분해 전 원본)
│   ├── 정책/        # 규제·보조금·관세 원문 발췌
│   └── 뉴스/
└── 계산/
    └── YYYY-MM-DD-채점표.json 또는 .md   # 경쟁력 축·기업별 상중하·서열
```

## raw 자료 파일 규칙

모든 `자료/` 파일은 맨 위에 최소 frontmatter를 단다 — 나중에 이 숫자를 다시 쓸 때
"언제, 어디서 가져온 값인가"가 파일 자체에 남아야 한다.

```yaml
---
수집일: YYYY-MM-DD
기준일: YYYY-MM-DD        # 데이터 자체의 기준 시점 (수집일과 다를 수 있다)
출처: <URL 또는 문서명>
---
```

- 파일명은 반드시 `YYYY-MM-DD-` 로 시작한다 (수집일 기준).
- raw 파일에는 해석·판단을 쓰지 않는다. 숫자·표·발췌만. 해석은 리포트에서.
- 같은 날 같은 종류를 다시 수집하면 새 파일을 만들지 말고 기존 파일에 추가한다.

## 스킬 실행 시 동작 규칙

1. **분석 시작 시**: `자료/` 를 먼저 훑는다. 기준일이 오늘과 가까운(시세 1일, 재무·공시
   90일 이내) raw 가 있으면 재수집하지 않고 재사용한다 — 없거나 오래된 것만 수집한다.
2. **수집하면서 저장한다**: 웹에서 가져온 원데이터는 리포트에 넣기 전에 `자료/` 하위에
   먼저 기록한다. 리포트의 모든 표는 `자료/` 파일에서 나와야 한다.
3. **계산은 `계산/` 을 거친다**: assumptions.json 을 쓰고 → valuation.py 실행 →
   valuation.json 저장 → 리포트에는 스크립트가 출력한 표를 붙인다.
4. **리포트 저장 전**: validate_report.py 게이트를 통과해야 한다 (통과할 때까지 수정).
5. 폴더가 없으면 만든다. 리포트 루트에는 완성 리포트 외의 파일을 두지 않는다.
