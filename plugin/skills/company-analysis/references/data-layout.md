# 리서치 워크스페이스 레이아웃 — raw 자료와 분석의 분리

> 스킬이 프로젝트 폴더에서 실행될 때 생성하는 모든 파일의 위치 규칙이다.
> 원칙: **raw 수집 자료는 `자료/`, 완성 리포트는 `분석/`, 계산 중간산출물은 `계산/`.**
> raw 를 분리 보관하는 이유 — ①다음 분석이 재수집 없이 증분 갱신할 수 있고 ②리포트의
> 모든 숫자를 원자료로 역추적할 수 있으며 ③트래커(데일리 수집)가 같은 폴더에 쌓인다.
> 시세(주가·시총)는 계속 변하는 값이라 raw 로 쌓지 않는다 — 계산 시점 스냅샷은 기준일과
> 함께 `계산/*-assumptions.json` 에 이미 기록되므로 그것으로 충분하다.

## 기업

```
리서치/기업/<종목명>/
├── 자료/                           # raw 수집 자료 — 수집한 그대로, 해석 없이
│   ├── 재무/YYYY-MM-DD-재무추이.md      # 3~4년 매출·이익률·ROE·부채·현금흐름 표 (공시 원본)
│   ├── 공시/YYYY-MM-DD-<제목>.md        # 공시 목록·주요사항·지분거래·지배구조 (dart.py 산출)
│   ├── 원본/YYYY-MM-DD-사업보고서-<접수번호>/  # 정기보고서 원본 XML + 목차별 md 분할
│   │   ├── INDEX.md                     #   섹션 목록(주석 ★) + 주석 독해 체크리스트
│   │   ├── <원본파일>.xml               #   원본 그대로 보존 — 수치 인용 시 대조 기준
│   │   └── NN-<섹션제목>.md             #   목차 단위 (사업의 내용, 주석, 감사보고서 …)
│   ├── IR/YYYY-MM-DD-<제목>.md          # IR 자료·가이던스·컨콜 발췌
│   ├── 뉴스/YYYY-MM-DD-뉴스클리핑.md    # 기사에서 취한 원데이터 (판매량·수출입 통계)
│   └── 유튜브/YYYY-MM-DD-<제목>.md      # 영상 자료 — IR 영상·컨콜·인터뷰의 전사/발췌 (URL·타임스탬프)
├── 분석/                           # 완성 리포트
│   ├── YYYY-MM-DD-기본분석.md
│   └── YYYY-MM-DD-심층분석.md
└── 계산/                           # 스크립트 입출력 — 재계산 가능해야 한다
    ├── YYYY-MM-DD-assumptions.json      # valuation.py 입력 (가정 전부 + 시세 스냅샷·기준일)
    └── YYYY-MM-DD-valuation.json        # valuation.py 출력 (9칸·낙점·진입가)
```

## 산업

```
리서치/산업/<산업명>/
├── 자료/
│   ├── 시장규모/    # 침투율·수요 통계 (금액 기준)
│   ├── 점유율/      # 기업·국가별 점유율 로데이터 (분해 전 원본)
│   ├── 정책/        # 규제·보조금·관세 원문 발췌
│   ├── 뉴스/
│   └── 유튜브/      # 산업 관련 영상 전사/발췌 (URL·타임스탬프)
├── 분석/
│   └── YYYY-MM-DD-산업분석.md
└── 계산/
    └── YYYY-MM-DD-채점표.json 또는 .md   # 경쟁력 축·기업별 상중하·서열
```

## raw 자료 파일 규칙

모든 `자료/` 파일은 맨 위에 최소 frontmatter를 단다 — 나중에 이 숫자를 다시 쓸 때
"언제, 어디서 가져온 값인가"가 파일 자체에 남아야 한다.

```yaml
---
수집일: YYYY-MM-DD
기준일: YYYY-MM-DD        # 데이터 자체의 기준 시점 (수집일과 다를 수 있다)
출처: <URL 또는 문서명>
---
```

- 파일명은 반드시 `YYYY-MM-DD-` 로 시작한다 (수집일 기준).
- raw 파일에는 해석·판단을 쓰지 않는다. 숫자·표·발췌만. 해석은 리포트에서.
- 같은 날 같은 종류를 다시 수집하면 새 파일을 만들지 말고 기존 파일에 추가한다.
- 유튜브 파일은 frontmatter 출처에 영상 URL을 적고, 인용 발췌마다 타임스탬프를 단다
  (예: `[12:34]`) — 나중에 원 발언을 재확인할 수 있어야 한다.

## 스킬 실행 시 동작 규칙

1. **분석 시작 시**: `자료/` 를 먼저 훑는다. 기준일이 90일 이내인 raw(재무·공시·IR)가
   있으면 재수집하지 않고 재사용한다 — 없거나 오래된 것만 수집한다. 시세(주가·시총)만은
   매번 새로 확인한다(저장은 assumptions.json 에).
2. **수집하면서 저장한다**: 웹에서 가져온 원데이터는 리포트에 넣기 전에 `자료/` 하위에
   먼저 기록한다. 리포트의 모든 표는 `자료/` 파일에서 나와야 한다.
3. **계산은 `계산/` 을 거친다**: assumptions.json 을 쓰고 → valuation.py 실행 →
   valuation.json 저장 → 리포트에는 스크립트가 출력한 표를 붙인다.
4. **리포트는 `분석/` 에 저장하고**, 저장 전 validate_report.py 게이트를 통과해야 한다
   (통과할 때까지 수정).
5. 폴더가 없으면 만든다. 종목/산업 폴더 루트에는 자료/·분석/·계산/ 외의 파일을 두지 않는다.
