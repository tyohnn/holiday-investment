## 요약 — 무엇이 부족한가 (2026-08-25 파일럿 후 정정)

| 구분 | 계정 수 | 상태 |

| **주석에서 추출 필요** | **39** | IS 세부 25 + CF 조정·운전자본 세부 14 |
| 그중 파일럿으로 확보 | 3 | 이자비용·유형자산감가상각비·기타무형자산상각비 |

**★ 정정 (파일럿 실측)**: 초판은 CF 세부 전반을 "주석"으로 분류했으나, **DART CF
본표가 이미 42개 세부 라인을 포함**한다(삼성 실측 — 유형자산의취득·배당금의지급·
이자의지급·법인세납부액 등 전부). "주석 필요"가 진짜인 곳은 **IS 세부**(DART IS는
17개 상위계정뿐)와 **CF 의 조정(현금유출없는비용 등)·운전자본 세부**(본표엔 `조정`
523,956 한 줄)다. FnGuide 계정명과 DART 계정명이 다른 경우는 해당 행에 병기했다.
