## 실행 중 발견·수정한 결함 10건

배치들이 스스로 발견해 보고했고, 감독이 재현·수정·회귀 검증했다. 전부 삼성전자 2개 회차
회귀(블록별 수치 완전 동일)를 통과했다.

| 결함 | 영향 |
|---|---|
| `parse_rd` 단위 하드코딩(백만원) | **72개사 232행이 1000배 오적재**. 대부분 회사는 천원 |
| 종속회사 기수 앵커 오적용 | 대한항공 2028A·대원제약 2072A·삼천당제약 2089A |
| 기간 라벨 미인식 18종 | 수백 행 유실 |
| 연혁 연도 `20\d\d` 한정 | 1999년 이전 설립사에서 연도가 내용으로 둔갑 |
| `num()` 괄호 음수·`▲` 미인식 | 행 단위 파싱 실패 |
| 주석 `외환차이` 유실 | 사전 존재 버그 |
| `account_detail` 고정 문자열 | 출처 표 구분 불가 |
| `llm_fallback` period_key 이중접미사 | ingest 100% 실패 |

**단위 결함 수정 근거**: 보령 R&D 46.3조원(매출 8,596억) → 463~558억원. 재적재 후
회사가 사업보고서에 직접 기재한 R&D 비중 **5.49% 와 정확히 일치**(독립 교차검증).

**앵커 교차대조**: 본문 앵커와 회계연도 역산이 1년 초과로 어긋나면 앵커를 폐기한다.
종속회사 기수를 쓰면 수십 년이 어긋나므로 이 조건이 판별한다. 정상 케이스(삼성)는
본문 앵커를 그대로 존중하는 것을 실측 확인했다.

## 알려진 미해결 (설계 결정 필요)

1. **OFS/CFS 대조 경로 부재** — 원문 '매출실적' 표가 별도(OFS)인데 `fin_periods` 는 연결
   우선이라, 자회사 있는 회사에서 부문합 게이트가 30~58% 차이로 **구조적으로 실패**한다.
   10개사 이상에서 반복됐다. 게이트가 나쁜 데이터를 막은 건 옳지만 옳은 데이터도 막는다.
2. **게이트 스킵 = 미검증 적재** — `fin_periods.revenue` 가 NULL 이면 게이트가 스킵되고
   데이터는 그대로 들어간다. "스킵"과 "통과"가 같은 결과를 낸다.
   실측 **250행 / 22개사 (segment_revenue 의 5.1%)**. 보험사만이 아니다.
   → status 에 '미검증' 을 명시하거나 보류로 바꿔야 downstream 이 신뢰도를 판단할 수 있다.
3. **과거 방향 앵커 오류** — 미래연도 방어는 미래로 튀는 것만 잡는다. 과거로 밀리는 것은
   부문합 게이트가 2차 방어선이지만 완전하지 않다.
4. **지주회사 스코프 기준** — 종속회사 사실을 당사 것으로 볼지 배치마다 판단이 갈렸다.
   DL·사조대림·대웅·대신증권·두산·효성 등. 일관 기준이 필요하다.
5. **시장점유율 "누구의 것인가"** — 원문 섹션 제목이 '시장점유율'이어도 내용이 고객사·
   경쟁사·산업 구성비인 경우가 많다. 대원산업 45행이 이 유형으로 오적재됐다(합계 100%가
   신호). 배치 24부터 판정 규칙을 지시서에 넣었고 이후 배치들이 실제로 걸러냈다
   (녹십자·서울도시가스·GS글로벌·SIMPAC 등).

## 기록의 한계

배치별 상세 보고서 37건과 폴백 산출물(22MB)은 실행 시점 `/tmp` 에 있었고 **커밋되지
않았다**. `ingest_progress` 에도 이 작업 단계가 없다(Phase 3 수집 단계만 추적). DB 에
남는 것은 결과 행의 `extracted_by`·`extracted_at`·`source_rcept_no` 뿐이라,
"처리했는데 0행이었다"와 "아직 처리 안 했다"가 구분되지 않는다 — 재실행 시 개선 대상.
