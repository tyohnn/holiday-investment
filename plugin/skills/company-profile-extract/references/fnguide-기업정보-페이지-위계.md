펼침 규칙 (재무제표 · 재무비율 · 투자지표)

- 행에 `+`가 있으면 부모다. 접근성 문구는 **계산에 참여한 계정 펼치기**.
- 화면 깊이는 최대 3단: `LVL 0` 굵은 합계/그룹 → `LVL 1` 상시 노출 계정 → `LVL 2` 접힌 세부(또는 산식 구성항).
- **LVL 3은 없다.** `판매비와관리비 > 인건비및복리후생비`까지가 끝이다. 급여·복리후생 같은 더 아래는 이 화면에 없다.
- `연결` / `별도`, 표마다 `연간` / `분기` 토글이 있다(쿠키로 기억).

```
├─ 주가관련 지표
│  ├─ 열: 연도마다 최고 / 최저 (최근 연·분기는 최고·최저만)
│  └─ 행: 주가(원) · 시가총액 · PER · PBR
└─ 기업가치 지표
   ├─ Per Share
   │  ├─ EPS (원)                    당기순이익(지배) / 수정평균발행주식수
   │  │  ├─ 당기순이익(지배)
   │  │  └─ 수정평균발행주식수 (주)
   │  ├─ EBITDAPS (원)               EBITDA / 수정평균발행주식수
   │  │  ├─ EBITDA                   영업이익 + 유무형자산상각비
   │  │  └─ 수정평균발행주식수 (주)
   │  ├─ CFPS (원)                   현금흐름 / 수정평균발행주식수
   │  │  ├─ 현금흐름                 당기순이익 + 감가상각비
   │  │  └─ 수정평균발행주식수 (주)
   │  ├─ SPS (원)                    매출액 / 수정평균발행주식수
   │  │  ├─ 매출액
   │  │  └─ 수정평균발행주식수 (주)
   │  └─ BPS (원)                    자본총계(지배) / 수정기말발행주식수(자사주차감)
   │     ├─ 자본총계(지배)
   │     └─ 수정기말발행주식수(자사주차감) (주)
   ├─ Dividends
   │  ├─ 수정DPS(보통주,현금) (원)   DPS(보통주,현금) × 무상조정수정계수
   │  │  ├─ DPS(보통주,현금)
   │  │  └─ 무상조정수정계수 (보통주)
   │  ├─ 수정DPS(우선주,현금) (원)
   │  │  ├─ DPS(우선주,현금)
   │  │  └─ 무상조정수정계수 (우선주)
   │  └─ 현금배당성향 (%)            배당금(현금) / 당기순이익(지배)
   │     ├─ 배당금(현금)
   │     └─ 당기순이익(지배)
   ├─ Multiples
   │  ├─ PER                         보통주수정주가(기말) / 수정EPS(직전4분기)
   │  │  ├─ 보통주수정주가(기말)
   │  │  └─ EPS
   │  ├─ PCR                         보통주수정주가(기말) / 수정CFPS
   │  │  ├─ 보통주수정주가(기말)
   │  │  └─ CFPS
   │  ├─ PSR                         보통주수정주가(기말) / 수정SPS
   │  │  ├─ 보통주수정주가(기말)
   │  │  └─ SPS
   │  ├─ PBR                         보통주수정주가(기말) / 수정BPS
   │  │  ├─ 보통주수정주가(기말)
   │  │  └─ BPS
   │  ├─ EV/Sales                    EV / 매출액(직전4분기)
   │  │  ├─ EV                       시가총액 + 순부채
   │  │  └─ 매출액
   │  └─ EV/EBITDA
   │     ├─ EV
   │     └─ EBITDA
   └─ FCF                            ← 이 그룹은 펼침 없음
      ├─ 영업활동으로인한현금흐름
      ├─ CAPEX                       (C/F)유형자산의증가
      └─ FCF                         영업활동으로인한현금흐름 − CAPEX
```

## 위계를 한 장으로

| 페이지 | 한 줄 | 펼침이 있는 곳 |
|---|---|---|
| Snapshot | 시세·수급·컨센서스·요약재무 랜딩 | 없음 (Financial Highlight는 들여쓰기만) |
| 기업개요 | 정체·연혁·구성·사람·관계사 | 없음 |
| 재무제표 | IS/BS/CF 요약계정 | 부모 계정 → LVL 2 세부. **여기가 가장 깊다** |
| 재무비율 | 안정/성장/수익/활동 | 비율 → 산식 구성 계정 |
| 투자지표 | 스타일·주당·배수·FCF | Per Share/Dividends/Multiples → 산식 구성항 |
| 컨센서스 | 실적 vs 추정, 증권사 목표 | 매출·영업이익·순이익 아래 전년비/컨센비 |
| 지분분석 | 구분·명부·변동 20건 | 없음 (탭) |
| 업종분석 | 종목 vs WI26 vs 섹터 vs KOSPI | 지표 → 분자/분모 |
| 경쟁사비교 | 해외 peer 펀더멘털 + 국내 임직원 | 없음 (그룹 헤더만) |
| 거래소공시 | 거래소 공시 리스트 | 없음 |
| 금감원공시 | DART iframe | 없음 |

같은 개념이 페이지마다 깊이가 다르다. Snapshot Financial Highlight의 `당기순이익(지배)`는 한 줄이고, 재무제표는 `당기순이익 > (지배주주지분)당기순이익`이며, 컨센서스는 그 위에 `전년동기대비`/`컨센서스대비`를 한 단 더 얹는다. 화면을 맞출 때는 **재무제표 LVL 2 목록이 계정 사전의 상한**이다.

관련 문서: `fnguide-재무제표-계정체계.md`(계정별 출처·값), `fnguide-추출-계획.md`(기업개요 블록 → 원문 매핑).
