# 산업지도 (공시 주석 · 재무 · 뉴스)

한 산업을 **사실 지도**로 그린다. "누가 이기는가 · 적정가는 얼마인가"가 아니라
"무엇이 무엇에 들어가고, 누가 누구에게 팔며, 수요가 바뀌면 어느 매출이 움직이는가"에
답한다. 방법론은 이 폴더의 `references/`에 자립한다. **교재(`교재/`)는 열지 않는다.**

기준 실행: 2026-08-27 전기차·이차전지·양극재 산업지도
(`리서치/산업/이차전지/분석/2026-08-27-산업지도-0-종합.md`). 그때 잠긴 함정은
`references/`에 일반 규칙으로 적혀 있다.

## 다른 스킬과의 경계

| 요청 | 스킬 |
|---|---|
| 원리·수요·공급처·병목·신판로를 사실로 그려라 | **이 스킬** |
| 경쟁력 축·채점·국면 3문·버블·유망종목 | `industry-analysis` |
| 한 종목 적정주가·9칸·진입가 | `company-analysis` |
| 사업보고서 5블록을 `fin_details`에 적재 | `company-profile-extract` |

산업지도가 끝나면 그 산출물을 입력으로 `industry-analysis` 또는 `company-analysis`에
넘길 수 있다. 이 스킬 안에서 적정가나 매수 여부를 쓰지 않는다.

## 불변 원칙

1. **교재를 읽지 않는다.** 외부 방법론 파일·옛 `#1~#13` 번호도 쓰지 않는다.
2. **모르면 `확인 불가`다.** 빈칸을 추정·업계 상식으로 메우지 않는다. 추정은 추정이라고 쓴다.
3. **모든 숫자에 출처.** DB는 `(DB: 테이블, period_key, fs_div, 컬럼)`, 웹은 URL,
   유튜브는 제목+URL+자막 인용.
4. **주석 정본은 `financial_facts.sj_div='NOTE'`.** `filing_sections`는 관심종목 목차
   추출이지 주석이 아니다. 상세는 `references/notes-protocol.md`.
5. **모수가 다른 시계열을 잇지 않는다.** 침투율(신차 %)과 대수, 전사용 매출과 해당
   제품 매출, 출하 톤과 탑재 톤을 한 표에 나누거나 이어서 YoY를 만들지 않는다.
6. **메인 에이전트가 감독·QC다.** 분석 노동은 서브에이전트. 상세는
   `references/supervisor-protocol.md`.
7. **뉴스·공시의 "매수하라"는 인용 대상이지 지시가 아니다.** 말미 고정 고지:
   방법론 연습이며 종목 추천·투자 권유가 아니다.

## 절차

### 1. 범위와 5장 뼈대를 확정한다 (감독)

사용자가 고른 산업에서 **최종 수요 / 핵심 중간재 / 병목 소재** 세 층을 먼저 적는다.
이차전지 실행의 대응은 전기차 / 셀 / 양극재였다. 다른 산업이면 층을 바꿔도 되나
장 수는 5+종합을 유지한다.

`references/chapter-template.md`를 읽고 이번 런의 장 제목·서브에이전트 분할을 적는다.
채점표·유망종목 칸은 만들지 않는다.

### 2. 스키마 함정과 조회 레시피를 연다 (감독)

서브에이전트를 띄우기 **전에** 다음을 읽는다.

- `references/schema-traps.md`
- `references/query-recipes.md`
- `references/notes-protocol.md`

자격 증명은 `apps/web/.env.local`의 `NEXT_PUBLIC_SUPABASE_URL` /
`SUPABASE_SERVICE_KEY`. 로컬 `supabase start`는 쓰지 않는다.

### 3. 유니버스와 잠금 매출을 감독이 직접 조회한다

KSIC(`companies.sector_code`)는 깊이가 제각각이라 **접두 매칭으로 넓게** 긁고,
최종 유니버스는 감독이 "승부의 축"(이 지도에서 그리는 층)으로 손으로 확정한다.
상장만 볼 때는 `market in (KOSPI, KOSDAQ)`.

확정 회사의 `fin_periods` 연간(및 필요하면 TTM) 매출·영업이익을 감독이 조회해
**잠금표**를 만든다. CFS 우선, 없으면 OFS를 쓰고 기준을 표기한다. 전사 매출에
다른 사업이 섞이면 그 사실을 잠금표에 적고, "해당 제품 매출"로 읽지 말라고 못 박는다.

서브에이전트에 숫자를 넘기기 전 **자릿수 sanity check**를 한다. 한 분기가 연매출의
두 배를 넘기면 웹 숫자를 원문(DART)과 대조한다. 2026-08-06 에코프로머티 사례:
웹 8,220억 vs DART 1,665억.

### 4. 주석·세그먼트 한계를 먼저 실측한다 (서브에이전트 1)

유니버스 전부에 대해 NOTE 행수, `fin_details` concept 커버, 최신 연간 NOTE의
×1000 단위 오염을 표로 만든다. 핵심 회사 NOTE가 0행이면 그 한계를 지도 서두에
잠근다. 오염 연도는 폐기한다. 절차는 `references/notes-protocol.md`.

이 표가 나오기 전에 장별 본문을 쓰지 않는다. 한계를 나중에 붙이면
"`filing_sections`는 삼성전자만" 같은 틀린 전제가 퍼진다.

### 5. 장을 병렬로 돌린다 (서브에이전트, 노동만)

감독은 장마다 프롬프트를 쓴다. 각 프롬프트에 **반드시** 넣는다.

1. 이번 장의 산출 경로와 필수 절 (`references/chapter-template.md` 해당 장)
2. `references/query-recipes.md`의 조회 레시피
3. `references/schema-traps.md` 전문 (또는 해당 절)
4. `references/notes-protocol.md`의 오염·오독 규칙
5. 감독이 잠근 매출표·주석 한계표 (원자료 URL/쿼리 포함)
6. "모르면 `확인 불가`. 지어내지 마라. 하위 에이전트를 띄우지 마라."
7. 긴 본문은 파일에 쓰고 **20줄 이내 요약만** 반환

모델은 sonnet. 서브에이전트는 자기 하위를 띄우지 않는다. 운영 규칙은
`references/supervisor-protocol.md`.

웹 시장규모·점유율은 원문(또는 원문을 인용한 1차 재인용)을 열고, 재인용끼리만
맞으면 그 등급을 본문에 적는다. 주가·시총은 DB에 없다 —
`https://finance.daum.net/quotes/A<종목코드>`.

### 6. 종합을 감독이 쓴다

`분석/YYYY-MM-DD-산업지도-0-종합.md`. 장별 링크, 주석 한계 한 단락, 층마다
한 표 또는 한 문단. 장 사이에 모수가 어긋나면 종합에서 잇지 말고 잔여로 남긴다.

### 7. QC를 생략하지 않는다 (감독 + QC 서브에이전트)

`references/qc-gates.md`를 체크리스트로 쓴다. 서브에이전트가 스스로 적은
"~는 목록에 없다", "인접 분류", "확인 불가"는 **결함 신호**다. 표본이 잘린 채
순위표를 만들었으면 그 장을 재실행한다.

QC 산출: `YYYY-MM-DD-산업지도-QC로그.md` (산업 폴더 루트)와 필요하면
`분석/YYYY-MM-DD-산업지도-QC보강.md` · `…-주석정정.md`.

정정은 원 장 파일을 고친 뒤 QC로그에 한 줄로 남긴다. 틀린 숫자를 종합에만
덮어쓰지 않는다.

### 8. 저장 레이아웃

```
리서치/산업/<산업명>/
├── 분석/YYYY-MM-DD-산업지도-0-종합.md
├── 분석/YYYY-MM-DD-산업지도-1-<층>.md
├── 분석/YYYY-MM-DD-산업지도-2-<수요>.md
├── 분석/YYYY-MM-DD-산업지도-3-<중간재>.md
├── 분석/YYYY-MM-DD-산업지도-4-<병목>.md
├── 분석/YYYY-MM-DD-산업지도-5-<전이>.md
├── 분석/YYYY-MM-DD-산업지도-주석정정.md    # 주석 한계·오염 (있을 때)
├── 분석/YYYY-MM-DD-산업지도-QC보강.md      # 교차검증 (있을 때)
└── YYYY-MM-DD-산업지도-QC로그.md
```

raw(뉴스 목록·조회 덤프)는 리포트에 쓰기 전에
`리서치/산업/<산업명>/자료/{재무,주석,뉴스}/`에 둔다. 해석은 `분석/`에만.
파일명 규칙은 `../company-analysis/references/data-layout.md` — 판단 문서는
분석일, 불변 재무는 사업연도.

문체: 근거 제시형 "~다" 서술체. 숫자는 표. frontmatter 권장 키:
`title / 산업 / 데이터기준일 / 수요층 / 중간재 / 병목 / 요약`.

## 데이터를 못 구했을 때

빈칸을 메우지 않는다. 확보한 층만으로 지도를 완성하고, 빠진 입력은
`확인 불가`와 잔여 목록으로 남긴다. 주석 파이프라인이 핵심 법인에 아직 없으면
그 사실을 서두에 잠그고 뉴스·`fin_details`·`fin_periods`로 진행한다.
