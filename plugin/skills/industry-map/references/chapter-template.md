# 장 뼈대

산업마다 층 이름은 바뀌나, 질문은 고정이다. 이차전지 실행(2026-08-27)의 층은
괄호 안에 적었다.

각 장 서두 고정 문장:

> 데이터 기준일 YYYY-MM-DD. 교재는 참고하지 않는다. 확인하지 못한 값은
> `확인 불가`. 투자 자문이 아니다.

감독이 잠근 매출표가 있으면 장 0절에 그대로 두고, 서브에이전트가 다시 계산하지 않는다.

## 0. 종합

- 주석·세그먼트 한계 한 단락 (정본 테이블, 핵심사 NOTE 0행, 오염 폐기).
- 장 1~5 링크.
- 층마다 한 표 또는 한 문단. 장 사이 모수가 다른 숫자를 한 줄로 잇지 않는다.
- 말미: 종목 추천이 아니다.

경로: `분석/YYYY-MM-DD-산업지도-0-종합.md`

## 1. 원리 · 제품군 · 메인 벤더 · 밸류체인 (이차전지)

필수 절:

1. 제품이 작동하는 방식 — 초심자가 층을 따라갈 한 단락.
2. 상용 종류 표: 한 줄 정의 · 누가 많이 만드나 · 상용/샘플 구분.
3. 밸류체인 한 줄: 상류 → 병목 → 중간재 → 팩/모듈 → 최종 수요.
4. 한국 상장 유니버스와 **전사 매출에 섞인 사업** (지주·정유·전자재료).
5. 세계 중간재 점유(출처 있는 연도만).

발표 ≠ 양산. "전고체 2027"은 목표로 쓰고 상용 열에 넣지 않는다.

## 2. 최종 수요 시장 (전기차)

필수 절:

1. 세계 성장 — 대수와 금액을 섞지 않는다. 출처가 갈리면 둘 다 적고 부호가 다른지 표시.
2. **침투율 = 신차 대비 %.** 보유 대수(스톡)와 나누지 않는다.
3. 지역 — 같은 나라에서도 소매/도매/수출 모수가 갈릴 수 있다.
4. OEM — 플러그인 판매와 완성차 전사 매출을 잇지 않는다.
5. 정책·인프라(충전, 보조금 종료일) — 날짜를 적고, 그 날 이후 숫자를 종료 전 숫자와 이어서 이야기하지 않는다.

시장 전체가 움직인 날의 개별 등락은 종목 재료가 아니다.

## 3. 중간재 공급 지도 (셀 — 누가 누구에게)

필수 절:

1. 폼팩터·스펙 종류.
2. 확정 공급 관계 표: 공급사 → 고객 → 제품/화학 → 금액·기간 · 출처 등급
   (공시 원문 / 공시를 인용한 언론 / 언론만).
3. 멀티 벤더 고객은 한 칸에 몰지 않는다 (테슬라 = 파나소닉 NCA + LG엔솔 NCM +
   중국 LFP + 자체 4680).
4. 계약의 용도를 읽는다. LG엔솔 43억 달러 LFP는 메가팩 **ESS**이지 EV가 아니었다.
5. 중국 포함 점유와 **비중국** 점유를 따로. "중국을 빼면 한국이 이긴다"를 가정하지 않는다.

## 4. 병목 소재 (양극재)

필수 절:

1. 세계 출하 — 용도 모수(전체 출하 vs 특정 수요 탑재)를 제목에 쓴다.
2. 소재 종류가 어느 중간재에 들어가는지.
3. 국내 벤더 · 성장 · 공장. 톤과 원을 분리한다.
   톤이 거의 그대로인데 원이 반토막이면 메탈 패스스루·믹스 변화를 의심하고,
   둘을 분리할 수 없으면 분리 불가를 적는다.
4. 확정 공급 계약 (공시 우선). 보도만 있으면 보도 등급.
5. 신제품(LFP 전환 등)은 양산/준양산/샘플을 구분. 매출 주인공이 아니면 그렇게 쓴다.

## 5. 전이 · 신흐름 · 신판로

필수 절:

1. 수요 변화가 병목 **원(₩)** 에 달리는 경로 표 (대수 +, 믹스 변화, 메탈가, 정책).
2. 헤드라인 신수요(로보택시 등)는 **절대 규모**를 기존 수요(GWh·톤)와 비교.
   케미스트리/스펙을 모르면 확인 불가.
3. 신판로(ESS, 데이터센터, 기타) — 숫자와 계약이 있는 것만 크게, 사례만 있으면 사례로.
4. 중국 제외 성장이 누구에게 가는지. 비중국 수요 성장 ≠ 한국 점유 성장.
5. 대당 용량을 깎는 대체(하이브리드 등)는 수요를 깎는 힘으로 적는다.

## 장에 넣지 말 것

- 경쟁력 상/중/하 채점, 9칸, 진입가, "사라/사지 마라".
- 교재 문장 인용, 증권사 투자의견.
- 잠금표를 서브에이전트가 재계산한 다른 숫자.
