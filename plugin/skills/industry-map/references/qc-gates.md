# QC 게이트

감독이 종합 전에, 그리고 푸시 전에 본다. 한 칸이라도 실패하면 그 장을 고치거나
재실행한다.

## 표본

- [ ] PostgREST 1000행에 잘린 순위표가 없다. 잘렸으면 페이지네이션 후 재작성.
- [ ] KSIC 정확 일치만으로 peer를 잘라 핵심사가 빠지지 않았다.
- [ ] 서브에이전트의 "목록에 없다 / 인접 분류 / 확인 불가"가 표본 결함인지
      진짜 공백인지 감독이 판정했다.

## 주석

- [ ] 주석을 `filing_sections`로 읽지 않았다.
- [ ] 유니버스 NOTE 행수·오염 연도가 표로 잠겨 있다.
- [ ] ×1000 오염 연도 숫자를 본문·종합에 쓰지 않았다.
- [ ] NOTE 각주(감가·이자)를 고객·공장 서술이라도 읽지 않았다.
- [ ] 세그먼트 라벨을 화학·파워트레인으로 재해석하지 않았다.

## 모수 · 산술

- [ ] 침투율(신차 %)과 보유 대수, 대수와 금액을 나누거나 잇지 않았다.
- [ ] 전사 매출을 해당 제품 매출로 읽지 않았다 (지주·정유·전자재료).
- [ ] 출하(전체 용도)와 특정 수요 탑재를 한 시계열로 잇지 않았다.
- [ ] 분기 숫자가 연간을 산술적으로 모순하지 않는다. 모순이면 원문 재조회.
- [ ] 전달된 웹 숫자가 DART·DB와 자릿수가 맞는다.

## 계약 · 뉴스

- [ ] 계약 용도(EV vs ESS 등)를 헤드라인만 보고 정하지 않았다.
- [ ] 멀티 벤더를 단일 공급으로 뭉개지 않았다.
- [ ] 공시 원문 / 공시 인용 언론 / 언론만을 등급으로 표기했다.
- [ ] 같은 기사를 인용하고도 `확인 불가`로 남은 숫자가 없다 (원문 재독).
- [ ] 유료 원문 미열람이면 재인용 교차와 그 한계를 본문에 적었다.
- [ ] 시장 급등락일을 종목 고유 재료로 쓰지 않았다.

## 신수요 · 신제품

- [ ] 헤드라인 신수요의 절대 규모를 기존 수요와 비교했다.
- [ ] 양산 / 준양산 / 샘플 / 목표 연도를 구분했다.
- [ ] 중국 제외 성장을 한국 점유 성장과 동일시하지 않았다.

## 산출물

- [ ] 장 파일 + 종합 + QC로그가 있다.
- [ ] 모든 표 숫자에 출처가 있다.
- [ ] 투자 권유 문장이 없고, 고지 문구가 있다.
- [ ] 정정은 원 장과 QC로그에 둘 다 반영됐다.
