## 요지
지주사를 통해 자회사에 투자할지는 "지분가치 × 지분율 × 할인율" 합산과 지주사 시총을 직접 계산해 비교하면 답이 나오며, 양극재 기술력의 본질은 업력이므로 에코프로비엠의 선두는 쉽게 뒤집히지 않는다.

## 핵심 주장
- 지주사 투자 여부는 감이 아니라 계산으로 판단한다. 네이버 시가총액만 있으면 누구나 할 수 있다.
- LG화학은 LG에너지솔루션 지분가치(50% 할인 후 27.6조)의 52%(14.5조)에 불과하므로 LG엔솔 직접 투자보다 LG화학이 유리하다. 지분가치만 제대로 평가받아도 상승률 90%.
- 우선주는 보통주의 통상 60% 수준인데 현재 그보다 낮으므로 LG화학은 본주보다 우선주가 낫다.
- 포스코홀딩스는 상장 자회사 지분가치 합계 7.4조, 시총 21.4조 → 나머지 14조가 철강 본업 + 비상장 지분가치인 셈. 이 14조를 어떻게 평가하느냐가 판단 기준이며, 이는 본인 몫이다.
- 현재 지주사 할인율 50%는 역사적으로 큰 편이며, 상법 개정 기대감으로 지주사 테마가 재평가되는 중(SK 등 상승).
- 지주사 ETF(TIGER 지주회사, 순자산 1,293억)로 자금이 유입되면 구성종목이 편입비율대로 수급을 받는다 → ETF 구성종목·PDF·엑셀 다운로드를 반드시 확인하라.
- 양극재 기술력의 핵심은 업력이다. 2004년 시작한 에코프로비엠이 국내 최고(30년 손맛 비유), 셀 제조사 CTO와 포스코퓨처엠 임원 모두 "에코프로비엠이 1위"라고 인정. 포스코는 2030년 무렵 역전을 목표로 추격 중.
- LMR은 고전압 미드니켈과 같은 맥락(망간 다량 사용)이며, 에코프로비엠은 2022년 3월 이미 "하이망간 양극재로 중국 LFP를 이긴다"고 발표했다. 기사에 안 나온다고 안 하는 게 아니다.
- 포트폴리오 구성은 ① 개별종목 밸류에이션 → ② 상승여력 순 나래비 → ③ 상관관계 반영 → ④ 8:2 법칙 → ⑤ 투자계좌 80%/투기계좌 20% → ⑥ 투자계좌 내 현금 20%의 순서로 한다.
- 비교로 인한 자괴감은 "내가 보는 나 / 남이 볼 것이라 생각하는 나 / 내가 되고 싶은 나" 세 자기의 간격 문제이며, 간격을 줄이는 노력(자기 절제, 커뮤니케이션 능력)이 해법이다.

## 방법론 — 교재① 재료

### 1. 지주사 vs 자회사 직접투자 판단 절차 (지분가치 합산법)
1. 대상 지주사의 상장 자회사 목록과 지분율을 확인한다(비상장 자회사는 별도 취급).
2. 각 상장 자회사에 대해 **지분가치 = 자회사 시가총액 × 지분율**을 계산한다.
3. 여기에 **지주사 할인율 50%**를 적용한다(현재 시장 관행 수준의 할인율).
4. 모든 상장 자회사의 할인 후 지분가치를 합산한다.
5. 지주사 시가총액과 비교한다.
   - 지주사 시총 < 합산 지분가치 → 지주사를 사는 것이 유리(자회사 지분만으로 이미 저평가).
   - 지주사 시총 > 합산 지분가치 → 차액이 "본업 가치 + 비상장 지분가치"에 대한 시장 평가액. 그 차액이 본업 가치보다 싸다고 판단되면 지주사, 아니면 자회사 직접 투자.

**사례 A — LG화학 / LG에너지솔루션 (2025년 6월 10일 기준)**

| 항목 | 값 |
|---|---|
| LG에너지솔루션 시총 | 67.5조 |
| LG화학 시총 | 14.5조 |
| LG화학의 LG엔솔 지분율 | 81.82% |
| 지분가치(할인 전) | 67.5조 × 81.82% ≈ 55.2조 |
| 50% 할인 후 지분가치 | 27.6조 |
| LG화학 시총 / 할인 후 지분가치 | 52% |
| 지분가치까지만 회복 시 상승률 | (27.6 − 14.5) ÷ 14.5 ≈ **90%** |

→ 양극재·기타 사업가치를 전부 0으로 놓아도 LG화학이 유리. 실제로 ㈜LG(지주사)가 5,000억 규모 자사 계열 지분 매입 계획 중 LG화학을 매수한다고 발표 — 회사도 알고 있다는 방증.

**사례 B — 포스코홀딩스 / 포스코퓨처엠 (동일 기준)**

| 항목 | 값 |
|---|---|
| 포스코퓨처엠 시총 | 9.8조 |
| 포스코홀딩스의 포스코퓨처엠 지분율 | 59.8% |
| 지분가치(할인 전) | 5.8조 |
| 50% 할인 후 | 2.9조 |
| 포스코인터내셔널 지분가치(할인 후) | 약 3.1조 |
| 상장 자회사 지분가치 합계 | **7.4조** |
| 포스코홀딩스 시총 | 21.4조 |
| 잔여(철강 본업 + 비상장 지분) 평가액 | 21.4 − 7.4 = **14조** |

→ 철강 본업 + 비상장 지분(포스코아르헨티나, 포스코필바라리튬솔루션 등)의 가치가 14조 이상이라고 판단되면 포스코홀딩스가 낫고, 아니면 포스코퓨처엠 직접 투자가 낫다. 판단은 본인 몫.

### 2. 우선주 vs 보통주 기준
- 통상 **우선주 주가 = 보통주의 약 60%**가 정상 수준.
- 현재 60% 미만이면 우선주가 상대적으로 싸다 → 본주 대신 우선주 매수.

### 3. 지주사 할인(홀딩컴퍼니 디스카운트) 개념
- 지주사 시총이 보유 자회사 지분가치 합보다 낮게 형성되는 현상. 이중계산(더블카운팅) 회피, 지배구조 불투명성, 배당·현금흐름 접근성 제약이 원인.
- 현재 할인율 50%는 과거 대비 큰 폭 — 지주사가 오랫동안 소외되어 있었기 때문.
- 상법 개정 기대감 → 지주사 재평가 논리가 부각되는 국면(SK 등 상승).

### 4. ETF 수급을 활용한 종목 점검법
1. 네이버에 "TIGER 지주회사 ETF" 검색 → ETF 페이지 진입.
2. 순자산 규모 확인(당시 1,293억). 운용사 마케팅으로 1조까지 커지는 사례 존재.
3. 구성종목 상위 10개 확인 → 한진칼, HD현대, SK, 두산, LG, 6위 포스코홀딩스 7.3% 등.
4. 하단 **구성종목 PDF / 엑셀 다운로드**로 전체 편입 종목·비중을 확인.
5. 유입 자금 × 편입비중으로 수급 규모를 추정(예: 1,300억 × 7.3% ≈ 100억 → 순자산 1조 시 약 1,000억 유입).

### 5. 포트폴리오 구성 5단계 (재정리)
1. **개별 종목 밸류에이션** — 신규 편입 후보(예: 장비주)도 반드시 직접 밸류에이션. "어렵겠죠, 어려워도 하셔야 됩니다."
2. **상승여력 순으로 나래비 세우기** — 상승여력이 큰 순으로 편입비중을 차등 배분.
3. **상관관계 보정** — 상관관계가 낮은 종목을 섞으면 포트폴리오 변동성이 축소됨. 7등짜리라도 상관관계가 낮으면 4~5등 자리 비중을 줄 수 있고, 보유 종목 수를 5개에서 7개로 늘릴 수도 있다.
4. **8:2 법칙** — 3년·5년 보유 시 10배·20배로 내 미래를 바꿔줄 확신 종목 3~4개에 80%, 나머지 아이디어(장비주 등)에 20%.
5. **계좌 분리** — 총 1억이면 투자계좌 8,000만원 / 투기계좌 2,000만원. 투기계좌에서 수익이 나 비중이 커지면 일부 매도해 20%로 되돌리고 남는 돈은 투자계좌로 이전. 반대로 확신 종목 주가가 부진하면 투자계좌 비중을 다시 8:2로 맞춘다.
6. **현금 비중** — 투자계좌 8,000만원 중 20%(1,600만원)는 항상 현금으로 보유. 기회라 판단되면 현금을 줄여 매수, 올랐을 때 팔아 다시 비중을 맞춘다 → 자동으로 "쌀 때 사고 비쌀 때 파는" 대응이 된다.

## 데이터·기술 — 교재② 재료

### 양극재 기술력 판별 기준
- **업력이 핵심**: 양극재는 아날로그적 기술이라 축적된 시간을 따라잡기 어렵다("30년 차 할머니 손맛"). 에코프로비엠은 2004년 개발 시작, 국내 최장.
- **검증 방법**: 기술력은 그 물건을 사서 쓰는 회사(셀 메이커)에게 물어보는 것이 가장 정확하다. 셀 제조사 기술 본부장(CTO)과 포스코퓨처엠 임원 모두 에코프로비엠을 1위로 지목. 포스코퓨처엠은 2030년 무렵 역전을 목표로 전사적 추격 중.

### LMR / 하이망간 계보

| 구분 | 내용 |
|---|---|
| LMR | Lithium Manganese Rich — 망간 비중을 높인 양극재 |
| 동의·인접 개념 | 고전압 미드니켈, 하이망간, OLO(과거 에코프로비엠 명칭) — 모두 망간 다량 사용이라는 동일 맥락 |
| 에코프로비엠 최초 언급 | 2022년 3월 31일 "하이망간 양극재로 중국 LFP 이길 수 있다" |
| 에코프로비엠 장기비전 발표 | 2022년 11월, 리튬망간리치(LMR) 포함 |
| 회사별 명칭 차이 | 동일 기술을 회사마다 다르게 부르고 시간이 지나면 이름도 바뀜 |

### NCM 조성 진화와 하이니켈 난이도

| 세대 | 조성 | 특징 |
|---|---|---|
| NCM111 | Ni:Co:Mn = 1:1:1 | 코발트 비중 높아 원가 부담 |
| NCM523/622 | 니켈 비중 상향 | 코발트 저감 |
| NCM811 / 9x계열 | 니켈 80~90%+ | 니켈↑ → 내구성↓, 혁신으로 85%까지 내구성·안정성 확보 |
| 농도구배형 | 코발트를 입자 외곽, 니켈을 중심부 배치 | 비용 절감 + 안정성 동시 확보. "가루 입자 안에 니켈을 몰아넣고 코발트로 감싼다"는 난이도 — 고려청자 비색에 비견되는 기술 장벽 |
| LMR / 고전압 미드니켈 | 망간↑, 니켈↓ | 원가 절감 방향의 또 다른 축 |

### GM LMR 관련 사실관계
- GM은 워런 테크니컬 센터에서 차세대 배터리 전략 발표(앤디 오우리, 배터리 및 지속가능 기획 수석 엔지니어).
- LG에너지솔루션·삼성SDI 등 한국 기업과 **각형 LMR 배터리** 생산 — LG엔솔 2개 공장, 삼성SDI 합작법인 1개 공장.
- 삼성SDI가 참여 → 삼성SDI가 쓰는 에코프로비엠 양극재도 자연히 포함된다.
- GM은 디지털 트윈 기술로 신차 개발 기간을 4년 → 2년으로 단축, 검증을 가상에서 반복해 비용·시간 절감. 전기차에서는 배터리 개발도 같은 시계에 포함됨.
- 미국 현지 생산 원칙 → **미국에 양극재 공장이 없으면 뒤처진다**. GM-포스코퓨처엠, 포드/스텔란티스-에코프로비엠, LG화학이 미국 시장을 지배할 구도.

- **교재① C5(상대가치·저평가 사다리)** 또는 신설 **PartI(증권 기초 개념 — 지주사)**: 지주사 할인·지분가치 합산법·우선주 60% 기준은 지주사/우선주 개념 정의와 계산 절차로 PartI에 넣고, LG화학·포스코홀딩스 실전 계산은 C5의 저평가 판별 사례로 연결.
- **교재① E1(자산배분 8:2), E2(종목편입 5단계), E3(현금 10~30%)**: 밸류에이션→나래비→상관관계→8:2→투자/투기 계좌 분리→현금 20%의 전체 절차가 이 세 챕터를 관통하는 통합 사례. 상관관계 분산 논리는 E2에 신규 항목으로 추가할 가치가 있음.

- **교재② A1~A4(과학원리) 및 E1~E5(기업분석)**: NCM 조성 진화·농도구배·LMR/하이망간 계보는 A계열, 에코프로비엠 업력 기반 기술력 우위 판정과 GM/포드/스텔란티스 파트너 구도는 E계열·D밸류체인에 배치.
