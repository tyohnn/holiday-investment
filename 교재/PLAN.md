# 교재/위키 구축 계획

## 목적
멤버십 강의 155편 전사본(약 543만 자)을 기반으로, 투자 사고방식을 재현할 수 있는 두 개의 탄탄한 교재이자 위키를 구축한다.

- **교재① 정량적 주식 평가 방법론** — 어떤 자료·뉴스를 보는지, 회사를 어떤 관점으로 분석하는지, 재무제표를 어떻게 읽는지, 정량적으로 어떻게 평가하는지
- **교재② 이차전지 과학·기술·밸류체인** — 과학 원리, 기술 한계와 로드맵, 산업 밸류체인, 기업별 기술·재무, 데이터 기반 전망과 주가 평가

## 원칙
- **강의 원본 중심**: 1차 버전은 강의 내용만 충실히 구조화 (외부 보강은 2차)
- **전 서술 출처 인용**: `[스킬업 4강 12:34]` 형식 (재생목록·강·srt 타임스탬프)
- **로컬 마크다운 위키**: Obsidian 스타일 `[[링크]]`, `주식공부/교재/` 아래 (노트·원본은 `주식공부/노트/` 계열)
- **단계별 검토**: 각 단계 산출물을 사용자 승인 후 다음 단계 진행

## 소스 매핑 (조사 완료)
| 소스 | 규모 | 역할 |
|---|---|---|
| 투자 스킬업 (1~46강, 48편) | ~48편 | 교재① 핵심 |
| 능력범위 향상 (1~38강) | 38편 | 교재② 핵심 |
| 특별 강좌 (피셔 15포인트) | 1편 | 교재① 정성분석 |
| 주식 상담소 | 39편 | 양쪽 보조 (개념 Q&A, 이차전지 2·8·9·13·37화) |
| 멤버십 전용 | 21편 | 보조 (밸류에이션 클래스 0·3~6강 단편, 시황) |
| 스타터 목록 | 8편 | 중복 → 제외 |

## 단계
### Phase 0 — 전처리 ✅→진행
- 보일러플레이트("한글자막 제공…") 및 도입 잡담 제거 규칙
- 음차 오류 교정표 (`용어교정.md`: 워렌 포펫→워런 버핏 등) — 노트 추출하며 계속 보강
- 특강 1편 중복 구간(재녹화 아티팩트) 등 이상치 기록

### Phase 1 — 편별 구조화 노트 (147편, 스타터 제외)
각 영상 → `노트/<재생목록>/<NN-제목>.md`:
- 메타(재생목록/강번호/길이), 한줄 요지, 핵심 주장(불릿)
- **방법론 추출** (교재① 재료): 절차·기준·공식·체크리스트
- **데이터 추출** (교재② 재료): 수치·기술 스펙·기업·밸류체인 정보
- 종목 언급(맥락 포함), 명언/원칙, 주요 대목 srt 타임스탬프
- **샘플 3편 먼저 → 사용자 검토 → 포맷 확정 → 전량 진행** (병렬 에이전트 배치)

### Phase 2 — 목차 설계
노트 전량 기반으로 두 교재의 챕터 구조(문서 목록) 설계 → **사용자 승인**

### Phase 3 — 챕터 집필
챕터별 관련 노트를 모아 합성 집필. 모든 주장에 출처 인용. 병렬 배치.

### Phase 4 — 위키화·검증
- `INDEX.md`(홈), 교재별 목차, 용어집, 종목 DB(언급 영상 역링크)
- 커버리지 검증: 147편 전부가 최소 1개 문서에 인용됐는지
- 샘플 사실 검증: 노트 vs 원문 대조 패스

## 폴더 구조
```
노트/
  원본 스크립트/<재생목록>/<NN-제목>/<NN-제목>.txt,.srt  ← 원본 전사·자막
  노트/투자스킬업|능력범위/<NN-제목>.md                    ← Phase 1

교재/
  PLAN.md / INDEX.md / 용어교정.md
  교재1-방법론/<챕터>.md              ← Phase 3
  교재2-이차전지/<챕터>.md            ← Phase 3
  종목/INDEX.md                        ← Phase 4
```
