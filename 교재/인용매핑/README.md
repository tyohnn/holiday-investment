# 교재 구루·원전 인용매핑

> 인용주석 달기용 작업 문서. 각 장에 쓰인 **개념·직접인용·응용**이 어느 구루·어느 원전에서 왔는지 부(部)별로 표로 정리한다.
>
> 정본 부·장 번호는 [전체 목차](../INDEX.md) 기준.
> 원전 목록: [참고문헌.md](../참고문헌.md). **파일럿:** 1권 A1–A4 본문에 GFM 각주(`[ ^id ]`) 삽입 완료(쪽수는 ★ 대기).

## 사용법

1. **부별 파일**에서 해당 장을 연다.
2. 표의 `인용 유형`을 본다.
   - **직접인용** — 교재에 이름·문구가 명시. 주석에 원전 페이지/연도를 달 후보.
   - **개념차용** — 구루 개념을 이름으로 쓰거나 거의 그대로 번역. 원전 확인 필수.
   - **응용** — 구루 프레임을 한국·이차전지·실전 규칙으로 번역. “원류 + 교재 응용”으로 주석.
   - **교재고유** — 저자 방법론. 구루 주석 불필요(또는 “원류 참고” 정도).
3. `주석용 메모`의 ★는 **원전 페이지/정확한 문장을 아직 못 박은 항목** — 인용주석 작업 시 우선 확인.

## 작성·갱신 원칙

- 교재 본문이 바뀌면 **해당 부 파일만** 갱신하고, 역색인도 함께 고친다.
- “느낌상 비슷함”만으로 구루를 붙이지 않는다. 본문에 이름·용어·구조가 있을 때만 행을 만든다.
- 교재고유 규칙을 구루 이름으로 포장하지 않는다. 원류가 분명할 때만 “응용”으로 표기.
