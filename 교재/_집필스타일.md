# 교재 집필 스타일 기준

> 이 문서가 `_템플릿-학습장.md`를 대체한다. 2026-07 개편에서 4A 라벨을 헤더로 노출한 방식은 폐기한다.
> 기준 모델: 『더 골』, 『설득의 심리학』, 『타이탄의 도구들』, 『부의 추월차선』 — 교수설계는 **뼈대로만** 쓰고 독자에게는 산문으로 보이게 한다.

## 1. 가장 중요한 원칙

**교수설계 용어는 집필자의 것이지 독자의 것이 아니다.**

좋은 책은 "여기는 Anchor 단계입니다"라고 쓰지 않는다. 독자가 아는 장면에서 시작해 자연스럽게 개념으로 넘어갈 뿐이다. 4A(Why→Anchor→Add→Apply)는 **집필할 때 순서를 점검하는 체크리스트**로만 쓰고, 문서에는 흔적을 남기지 않는다.

| 금지 | 대체 |
|---|---|
| `## 0. 왜 지금인가 (Why)` | 헤더 없이 도입 문단으로 |
| `## 1. 이미 아는 장면 (Anchor)` | 도입 문단 안에 비유·장면으로 녹임 |
| `## 2. 핵심 한 줄 (Add)` | `## 가치는 물건이 아니라 믿음에 붙어 있다` (내용어 헤더) |
| `## 4. 지금 해보기 (Apply)` | `## 직접 해보기` 또는 본문 마지막 문단 |
| `## 5. 흔한 오해 (Contrast)` | `## 여기서 사람들이 자주 틀린다` 등 내용어 |
| `> 오늘 끝내는 것: …` | 도입 문단에서 산문으로 예고 |

## 1.5. 독자 수준 — 가장 자주 어기게 되는 기준

**독자는 주식 계좌를 이제 막 열었거나 아직 열지 않은 성인이다.** 경제 뉴스는 보지만 "손절"이 뭔지 모르고, "PER"을 들어는 봤어도 뜻은 모른다. 전자책을 읽듯 술술 넘어가야 한다.

집필자가 어렵게 만드는 것은 문장 구조가 아니라 **설명 없이 지나가는 단어들**이다. 다음 셋을 지킨다.

**(1) 업계 은어를 쓰지 않는다.** 이미 주식을 해 본 사람만 아는 말이다.

| 쓰지 않는다 | 이렇게 쓴다 |
|---|---|
| 장이 무너진 날 | 주식시장 전체가 크게 떨어지는 날 |
| 손실을 확정하고 판다 | 산 값보다 싼 값에 팔아 손해를 그대로 떠안는다 |
| 물렸다 | 산 값보다 떨어져서 팔지 못하고 붙들려 있다 |
| 기법 / 정량 기법 | 방법 / 계산 방법 |
| 포지션 | 사 둔 주식 |
| 지표와 차트 | 주가 그래프와 각종 숫자 |
| 분할매수 | 나눠서 사기 |
| 괴리 | 벌어진 차이 |
| 리스크 프리미엄 | 위험한 만큼 더 요구하는 몫 |

**(2) 일상어로 먼저 말하고, 그다음에 그 이름을 알려준다.** 순서를 뒤집으면 그 문장에서 독자가 떨어져 나간다.

- 나쁨: `핵심은 자익권, 그중에서도 이익배당청구권이다.`
- 좋음: `회사가 번 돈을 나눠 받을 권리가 생긴다. 법에서는 이것을 이익배당청구권이라고 부른다.`

전문어를 **아예 안 쓰는 것이 목표가 아니다.** 독자는 결국 그 말을 알아야 하므로, 일상어로 이해시킨 뒤 이름표를 붙여 준다.

**(3) 처음 나오는 숫자 개념은 반드시 예를 든다.** 정의만으로는 절대 들어오지 않는다.

- 나쁨: `미래 현금흐름을 현재가치로 할인한 총액`
- 좋음: `3년 뒤에 받을 100만 원과 지금 손에 있는 100만 원은 값어치가 다르다. … 1년에 10퍼센트씩 값어치가 줄어든다고 보면, 3년 뒤의 100만 원은 지금 기준으로 약 75만 원이다.`

**짧은 단정문을 홀로 두지 않는다.** `이 장은 그 선을 긋는다.` 처럼 툭 끊는 문장은 글에 힘을 주는 것 같지만 초보자에게는 그냥 불친절하다. 무엇을, 왜, 어떤 순서로 하는지 이어서 풀어 준다.

## 2. 헤더 명명

헤더는 **그 절이 주장하는 내용**을 담는다. 목차만 훑어도 장의 논지가 읽혀야 한다.

- 좋음: `가치는 물건이 아니라 믿음에 붙어 있다` / `투자와 투기를 가르는 단 하나의 질문` / `감정을 이기는 것은 의지가 아니라 표다`
- 나쁨: `개념 정리` / `핵심 내용` / `2. Add` / `가치란?`

번호는 붙이지 않는다(`## 1.` 금지). 절 사이 순서는 서술이 만든다.

## 3. 장의 도입부

**H1 바로 다음은 본문이다.** 과거에 쓰던 머리말 인용 블록은 전 교재에서 제거했다(2026-07). 아래 형태를 되살리지 않는다.

```markdown
> 숫자로 읽는 주식투자 1권: … · 제1부
> 이 문서가 답하는 질문: …
> 오늘 끝내는 것: …
```

웹 페이지의 `description`은 `sync-content.mjs`가 첫 문단에서 자동으로 뽑으므로 따로 적지 않는다.

**도입부는 헤더 없이 3~5문단.** 다음을 이 순서로 담되, 라벨을 붙이지 않는다.

1. 독자가 겪는 구체적 장면이나 흔한 오해에서 출발
2. 그 장면이 왜 문제인지 — 이 장이 답할 질문이 자연스럽게 세워지도록
3. 이 장에서 무엇을 배우는지 한두 문장으로 예고 (사용자 요구: "장마다 초반에 어떤 개념을 배울지 언급")
4. 다른 장과의 위치 관계 (선행 개념 / 이어지는 장)

목록이나 표로 학습 목표를 나열하지 않는다.

## 4. 분량과 호흡

| 유형 | 목표 (한글 자수) | 현 코퍼스 기준 |
|---|---|---|
| 본편 장 | **1.2만 ~ 2.5만 자** | 1권 본편 30장 중앙값 1.25만, 최대 2.36만 |
| 케이스 장(H·2권 E부) | 1.5만 ~ 2.5만 자 | |
| 부록 절 | 6천 ~ 1.2만 자 | |

자수는 이렇게 센다.

```bash
python3 -c "import sys;print(len(open(sys.argv[1],encoding='utf-8').read()))" 교재/교재1-방법론/A1-투자의-본질.md
```


**하한이 기준이고 상한은 권고다.** 짧으면 "인지부하를 낮춘" 게 아니라 덜 쓴 것이다. 인지부하는 *장의 길이*가 아니라 *한 문단에 밀어 넣은 새 개념의 수*가 만든다. 낮추는 방법은 잘라내기가 아니라 **개념 하나를 여러 문단에 걸쳐 천천히 푸는 것**이다.

- 새 개념 하나당 최소: 정의 1문단 + 비유나 사례 1문단 + 반례나 오해 1문단
- 표는 이미 산문으로 설명한 것을 **압축해 되짚을 때만**. 표가 설명을 대신하면 안 된다
- 불릿은 절차·체크리스트처럼 본래 목록인 것에만. 논증을 불릿으로 쪼개지 않는다
- `→`, `·` 로 문장을 잇는 전보문체 금지. 문장은 문장으로 쓴다

## 5. 비유와 사례

개념마다 **독자가 이미 아는 것에 건다.** 강의 원본에 있는 비유(야프섬 돌화폐, 동네 가게 동업, 양산 장사·우산 장사 아들을 둔 엄마 등)는 자산이므로 축약하지 말고 서사로 편다. 비유는 한 문단 이상 풀어야 남는다.

숫자 사례는 **맥락과 함께** 쓴다. "상승 여력 580%"가 아니라 "2024년 9월 기준, 8대 종목 평균 상승 여력이 580%로 계산되던 시점에".

## 6. 분할 기준

파일을 나누는 조건은 **성격이 다른 두 주제가 한 장에 들어 있을 때**뿐이다. 길다는 이유만으로 나누지 않는다.

나눌 때는 각각이 **독립적으로 완결된 장**이어야 한다. 허브를 가리키는 껍데기 파일(`상세는 허브 참조`)은 만들지 않는다.

## 7. 연습과 도표

- 장 끝에 `## 직접 해보기` 한 개. 독자가 자기 종목·자기 계좌로 30분 안에 할 수 있는 것 하나. 퀴즈 여러 개로 채우지 않는다.
- `<!-- MEDIA -->` placeholder는 **말로 설명하기 어려운 것**에만 (구조도, 시계열 그래프, 프로세스 플로우). 장당 0~2개. 본문에 이미 있는 표를 도표로 또 만들지 않는다.
- `<!-- QUIZ -->` 블록은 원칙적으로 쓰지 않는다. 필요하면 `직접 해보기` 안의 질문으로 녹인다.

## 8. 마무리와 장 사이 연결

장의 마지막 절은 `## 핵심 요약`이다. 완결된 문장의 불릿 5~9개로, 본문을 안 읽어도 논지가 서도록 쓴다.

**`## 관련 챕터` 목록은 두지 않는다** (2026-07 전 교재에서 제거). 책 끝마다 붙는 링크 목록은 읽는 흐름을 끊고, 정작 필요한 순간에는 눈에 안 들어온다. 다른 장으로 보내는 일은 **그 이야기가 나오는 본문 그 자리에서** 한다.

- 나쁨: 장 끝에 `- [[C1-PER-바로-쓰기|9장 PER 바로 쓰기]] — PER 계산법`
- 좋음: 본문 중 `…구체적인 계산법과 세 가지 함정은 [[C1-PER-바로-쓰기|9장 PER 바로 쓰기]]에서 다룬다.`

**다른 장을 가리킬 때는 `[[파일명|N장 제목]]` 형식을 쓴다.**

**표 셀 안에는 위키 링크를 넣지 않는다.** 마크다운 표에서는 `|`를 `\|`로 escape해야 하는데, 그러면 링크 대상에 역슬래시가 붙어 웹에서 링크가 깨진다. 표에는 일반 텍스트를 쓰고 링크는 표 아래 문장에 둔다.

```markdown
[[C1-PER-바로-쓰기|9장 PER 바로 쓰기]]
```

독자에게는 `9장 PER 바로 쓰기`로 보이고, 링크가 걸리는 대상은 파일명이다. `C1`, `C2` 같은 파일 코드가 독자 눈에 보이면 안 되고, 반대로 `9장 PER 바로 쓰기`라고만 적어 두면 링크가 되지 않는다.

부 순서가 바뀌어 장 번호가 밀리면 **라벨만** 고치면 되고 링크는 깨지지 않는다. 번호 대조는 [`INDEX.md`](INDEX.md)가 정본이다.

## 9. 사실 충실도

- 강의 원본에 없는 사실을 추가하지 않는다. 보강은 `강의/노트/`의 미사용 재료에서만 끌어온다.
- 수치·고유명사는 `용어교정.md` 기준을 따른다.
- 강사의 시장 전망·정치적 해석은 **강사의 주장으로 귀속**해 서술한다("강사는 ~로 본다").

## 9.5. 인용 각주 (구루·원전)

본문 흐름을 해치지 않는 선에서, **직접인용**과 **핵심 개념의 첫 등장**에만 GFM 각주를 단다. 작업표는 [`인용매핑/`](인용매핑/README.md), 원전 목록은 [`참고문헌.md`](참고문헌.md).

**다는 것**
- 이름+따옴표가 있는 문장 (그레이엄·버핏·린치·피셔·코스톨라니 등)
- 그 책에서 **처음** 정의되는 구루 개념 (안전마진, 텐배거, 15포인트, PSR…)

**달지 않는 것**
- 교재 고유 운용 규칙 (3년 3배, 영업이익×0.8, 다층 8:2, 우선주 60% 룰 등)
- 이미 앞 장에서 각주를 단 개념의 재등장 (본문에서 “2장에서…”로 역참조)
- “응용” 수준으로만 빌린 프레임에 원전을 과장해 붙이기

**형식**

```markdown
"시장은 짧게 보면 투표 기계이고, 길게 보면 저울이다."[^graham-vote]

[^graham-vote]: 벤저민 그레이엄 — 버핏 등이 전하는 표현. 원류는 『현명한 투자자』·『증권분석』 전통 (쪽 ★). 목록: [[참고문헌|참고문헌]].
```

- 각주 ID는 의미 있는 영문 슬러그 (`graham-vote`, `lynch-tenbagger`).
- 정의 블록은 장 파일 **맨 아래**(핵심 요약 뒤)에 모은다.
- 쪽수가 미확정이면 `(쪽 ★)`만 쓰고 숫자를 지어내지 않는다.
- 장당 본문 각주는 대략 **5~12개**를 넘기지 않는다.

## 10. 커밋 전 점검

```bash
# 4A 라벨 잔존 검사
grep -rnE '^## [0-9]+\. .*\((Why|Anchor|Add|Apply|Contrast|Away)\)' 교재/
# 껍데기 문구 검사
grep -rn "허브에서 옮김\|옮길 자리\|상세는 허브" 교재/
# 비한글 혼입 검사 (키릴 등)
grep -rn "[а-яА-Я]" 교재/
# 분량 하한 검사
find 교재 -name "*.md" -size -8k
```
