# 교재 교수법 개편 계획 (실행본)

> 상태: Phase 0~4 실행. 이론 근거는 Cursor Canvas `adult-learning-pedagogy` 및 Knowles / Vella 4A / Sweller CLT / Rosenshine.
> 원칙: 강의 출처·기존 서술 충실도는 유지. 삭제하지 않고 **재배치·분할·학습 골격·placeholder**로 교수법을 올린다.

## 1. 진단 요약

| 축 | 현재 | 목표 |
|---|---|---|
| 목표 | `이 문서가 답하는 질문` 있음 | + `오늘 끝내는 것` (Away) |
| 구조 | 밀집 서술 → 핵심 요약 | Why → Anchor → Add → 사례 → Apply → Contrast → Away → 심화 |
| 연습 | 없음 | QUIZ/연습 placeholder 최소 1 |
| 시각 | 표 위주 | MEDIA(diagram/graph/image) placeholder 최소 1 |
| 난이도 | 초보·심화 혼재 | 입문 경로 / 심화 / 레퍼런스 이중 목차 |

## 2. 집필 규칙 (고정)

1. **한 학습장** = 질문 1개 + 핵심 명제 1개 + Apply 1회 + Away 1문장.
2. 핵심 경로 목표 **약 80~180줄**. 초과·H2 성격 혼재 시 분할.
3. 본문 순서: `0 Why` → `1 Anchor` → `2 Add` → `3 사례` → `4 Apply` → `5 Contrast` → `6 Away` → `심화` → `핵심 요약` → `관련 챕터`.
4. 기존 `핵심 요약` / `관련 챕터` / 질문 블록쿼트는 **유지** (sync-content 호환).
5. 템플릿 전문: [`_템플릿-학습장.md`](_템플릿-학습장.md)
6. 학습 경로 목차: [`목차-학습경로.md`](목차-학습경로.md)
7. **1권 부 순서 = A→I 알파벳** (제1부=A 철학 … 제9부=I 증권 기초). 증권 기초는 선수면 먼저 읽되 제1부가 아니다.

## 2.1 템플릿 학습장 — 모든 내용에 같은 구조가 가능한가?

**가능하되, “파일 역할”에 따라 깊이를 달리한다.** 섹션 이름(Why/Anchor/Add/Apply/Away)은 공유하고, 채우는 밀도는 세 등급이다.

| 등급 | 대상 | 템플릿 적용 |
|---|---|---|
| **학습장 (풀 템플릿)** | 입문 경로 `C2a`, `A2b`, 분할 `a/b/c` | 0~6절 + MEDIA + QUIZ + Away 전부. 핵심 경로 80~180줄 |
| **단장 템플릿** | 질문 1개인 유지 장 (A1, A2, B1…) | 같은 골격. 본문이 길면 Add에 핵심만, 나머지는 `심화` |
| **허브·레퍼런스** | `C2-….md` 통합본, 잘린 뒤의 원본 | 상단에 학습 경로 링크만. **Apply/QUIZ/Away 일괄 삽입 금지** (2026-07 허브에서 제거 완료). 본문 전체를 0~6으로 억지 재배치하지 않음 |
| **케이스 (H)** | H1~H4 | 대분할 없음. Apply 전용 재프레이밍(퀴즈·워크시트)만 덧붙임 — worked example 장과 페어 |
| **부록 트랙** | 생활·태도 절 | 풀 템플릿 가능하나 투자 절차 worked example 대신 “내일 실행 1가지” 비중↑ |

**한 줄 답:** 네, **학습 단위로 쪼개면** 거의 모두 같은 템플릿이 된다. 다만 위키 검색용 허브·초장문 레퍼런스까지 문장마다 4A로 다시 쓰면 인지부하와 유지보수만 늘므로, 허브는 “경로 안내 + 원문 보관”으로 둔다.

## 3. Placeholder 규약

HTML 주석 + 눈에 보이는 blockquote. id는 `book{1|2}-{파일stem}-{slug}` 권장.

```markdown
<!-- MEDIA:diagram|graph|image|table-upgrade id="…" -->
> **[도표|그래프|이미지|표시각화 · placeholder]** 제목
> - 형태: …
> - 데이터: …
> - 학습 목적: …
<!-- /MEDIA -->

<!-- QUIZ:recall|apply|contrast|transfer id="…" -->
> **[퀴즈|연습 · placeholder]** 유형: …
> - 문항 / 정답 키 / 피드백 …
<!-- /QUIZ -->
```

**학습장 최소**: MEDIA ≥ 1, QUIZ 또는 Apply ≥ 1, Away 1문장.

목록 export: [`placeholder-index.md`](placeholder-index.md)

## 4. 분할 트리거

다음 중 하나면 `분할` 검토:

- H2 ≥ 5이고 성격이 둘 이상 (개념 / 절차 / 역사 / 판정 / 케이스)
- 줄 수 ≥ 250
- “지금 할 수 있어야 할 일”이 여러 개

분류 결과 → [`목차-학습경로.md`](목차-학습경로.md)
