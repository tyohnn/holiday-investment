# 42강(투자 스킬업 40화) — 20% 현금 보유 Back Test
> 출처: 투자 스킬업 40강(재생목록 42번) · `원본 스크립트/【멤버십⭐전용】투자 스킬업/42 - 멤버십 회원 전용⭐ ｜ 40강 20%현금 보유 Back Test/42 - 멤버십 회원 전용⭐ ｜ 40강 20%현금 보유 Back Test.txt` · 길이 ~2:14 (srt 마지막 타임스탬프 02:14:20 기준)

## 요지
에코프로 실제 주가(2만→30만→4만→14만)로 "100% 몰빵" 대 "항상 현금 20% 유지 리밸런싱"을 백테스트하여, 20% 현금 유지는 초기 고점에서는 불리하지만 바닥과 회복 구간에서 일관되게 우위이며 그 진짜 목적은 수익 극대화가 아니라 훌륭한 주식을 10~20년 보유하게 해주는 멘탈 장치임을 입증한다.

## 핵심 주장
- 어떤 종목을 사느냐보다 그 종목을 어떤 식으로 보유·접근하느냐가 수익을 결정한다.
- "5천 깨지면 팔고 바닥에서 다시 사라"(이광수식 넥라인 붕괴 매매)는 바닥을 아무도 못 맞추므로 "싸게 팔고 비싸게 사기"를 반복하게 만드는 무책임한 조언이다.
- KOSPI 5,052(3월 초 저점 = 3/31 저점)가 시장 참가자들이 공유하는 넥라인이며, 이 선이 깨지면 손절매·투매가 일시에 쏟아진다. 정권의 "코스피 5천" 상징성 때문에 지지 시도도 겹치는 라인이다.
- 백테스트는 미래 성과의 보장이 아니라 "과거의 다양한 시장 상황에서 이 전략이 어떤 모습을 보였는지" 확인하는 도구다. 백테스트 기간을 유리하게 자르는 과최적화(대표 사례: "지난 10~15년 나스닥 QQQ 적립식이 최고"라는 주장)를 경계하라 — 2008년 이후 나스닥 우위는 모바일 혁명 수혜라는 '이유'를 이해해야지, 데이터 외삽으로 믿으면 안 된다.
- 퀀트/자산배분의 목표 수익률은 연 5~10%인데 그 정도면 지수 ETF로 충분하다. 인생을 바꾸려면 ~30%를 목표로 종목과 시장 접근법을 공부해야 한다.
- 에코프로 백테스트 결과: 초기 고점에서는 몰빵이 유리(이것이 몰빵 환상의 원천), 그러나 바닥과 재고점에서는 20% 현금 유지가 유리하며 변동성이 완화된다(덜 오르고 덜 빠진다).
- 매수가가 고점에 가까울수록 20% 현금 유지의 우위가 커진다 → 확장 규칙: 바닥권이면 현금 10%, 고점권이면 30%로 시작(10~30% 가변, 다음 강에서 백테스트).
- 20% 현금 유지의 진짜 목적은 저점·고점을 맞춰 돈을 더 버는 게 아니라 ①훌륭한 주식을 오래 보유하게 하고 ②하락 때 "뭔가 할 일"(리밸런싱)을 만들어 걱정을 없애는 것이다(카네기 자기관리론: 걱정을 없애는 법 = 계속 뭔가를 하는 것).
- 몰빵을 못 버리는 심리적 뿌리는 과신과 시기심이다. "누군가는 항상 나보다 빨리 부자가 되며 그것은 비극이 아니다"(찰리 멍거) — 시기심과 수익을 동시에 얻을 수는 없다.
- 20%의 의미 = 여유(멘탈)·겸손(내 판단이 틀릴 확률 20%)·경계(내가 모르는 것이 있을 확률 20%). 100%를 안 채우는 것이 과유불급의 실천이다.

## 방법론 — 교재① 재료
**20% 현금 비중 유지(8:2 리밸런싱) 절차**

1. **초기 설정**: 투자금의 80%만 매수, 20%는 현금으로 남긴다. (예: 1억 → 주식 8,000만 + 현금 2,000만)
2. **리밸런싱 트리거**: 주가가 크게 움직인 시점마다(주가가 의미 있게 움직이는 구간은 전체의 ~5%뿐, 그때만 액션) 아래 계산을 반복한다.
3. **리밸런싱 공식**:
   - 평가총액 = 주식 평가액 + 현금
   - 목표현금 = 평가총액 × 20%
   - 조정액 = 목표현금 − 현재현금
   - 조정액 > 0 → 그만큼 주식 **매도** (상승 후: 이익 일부 실현)
   - 조정액 < 0 → 그만큼 주식 **매수** (하락 후: 자동 저점 매수)
4. **현금 비중의 가변 운용(확장)**: 차트로 "얼마나 올라왔는지" 확인해서 — 바닥권 매수 시작이면 10%, 고점권(단기 4배 상승 같은 경우, 예: 삼성전자 5만→20만)이면 30%. 기본은 20%, 범위는 10~30%.
5. **현금 보관 형태**: 즉시 사용 가능한 형태로만. 3개월 예금 등에 묶지 말 것(이자 차익은 미미, 기동성이 본질).
6. **하지 말아야 할 것**: "지금 팔아서 저점에 전액 재진입" 같은 마켓타이밍 시도 금지 — 저점은 아무도 못 맞춘다. 하락이 확실해 보여도 10~30%는 항상 남긴다. 공매도·인버스 ETF 금지(소액이라도 포지션이 심리를 오염시켜 매수/매도 관점을 뒤집는다).
7. **포트폴리오 병행 원칙**: 한 종목 몰빵 금지, 5종목 이상 구성. 가장 많이 오른 종목을 일부 팔아 덜 오른 종목으로 옮긴다(에코프로 급등기에 LG에너지솔루션·LG화학·POSCO홀딩스로 분산 권고했던 사례).

**실수의 4단계 정의(반면교사 체크리스트)**
1. 고점에서 포모(FOMO)로 매수 — 얼마나 올랐는지 확인하지 않고 진입
2. 제일 많이 오를 것 같은 한 종목에 몰빵
3. 물리자 투기적 관점("단타")을 투자적 관점("장투")으로 슬쩍 변경 — 포모 진입 자체보다 관점 변경이 실패의 핵심. 단타로 들어왔으면 손절 기준을 지켜야 한다
4. 현금 비중 0 → 후회하고 남 탓

**현금 10% 최소선의 4가지 기능(제5원칙, 홍종원 글 인용)**
- ① 불가피한(강제) 매도 차단 — 돌발 지출이 생겨도 시나리오가 깨지지 않는다. 강제 매도는 "판 김에 바닥에서 주수 늘리자"는 악마의 속삭임으로 이어져 계좌를 망친다
- ② 심리적 여유 — "한 발 남아 있다"는 사실이 하락을 공포가 아닌 매수 기회로 보게 한다
- ③ 현금도 하나의 종목 — 새 종목 발견 시 물린 주식을 팔지 않고 진입할 수 있는 옵션
- ④ 학습 동력 — 현금이 있어야 "이 돈으로 살 만한 게 없을까"라며 새 종목을 공부하게 된다

## 케이스 데이터
**에코프로 백테스트** (액면분할 후 가격 기준, 경로: 2만 → 10만(B) → 20만(C) → 30만(23.7 고점) → 12만 → 8만 → 4만(25.5 바닥, 최저 3.8만) → 16만 → 14만(현재). 액분 전 환산 10만/50만/100만/150만)

### 케이스 A — 2만 원에 1억 투자
- 100% 몰빵: 1억 → **15억**(30만) → **2억**(4만) → **7억**(14만)
- 80:20 유지 (주식/현금, 만 원):
  | 시점 | 조정 전 | 계산 | 조정 후 |
  |---|---|---|---|
  | 초기(2만) | — | 1억×80% | 8,000 / 2,000 |
  | B(10만, ×5) | 40,000 / 2,000 | 총 4.2억×20%=8,400 → 6,400 매도 | 33,600 / 8,400 |
  | C(20만, ×2) | 67,200 / 8,400 | 총 7.56억×20%=15,120 → 6,720 매도 | 60,480 / 15,120 |
  | 고점(30만, ×1.5) | 90,720 / 15,120 | 총 **10억 584** (이후 10.6억=85,000/21,000으로 약식화) | — |
  | 12만(−60%) | 34,000 / 21,000 | 총 5.5억×20%=11,000 → 10,000 매수 | 44,000 / 11,000 |
  | 8만(−33%) | 29,000 / 11,000 | 총 4.0억×20%=8,000 → 3,000 매수 | 32,000 / 8,000 |
  | 4만(−50%) | 16,000 / 8,000 | 총 **2억 4천**×20%=5,000 → 3,000 매수 | 19,000 / 5,000 |
  | 16만(×4) | 76,000 / 5,000 | 총 8.1억×20%=16,200 → 11,200 매도 | 64,800 / 16,200 |
  | 14만(현재) | 56,700 / 16,200 | 총 **~7억 3천** | — |

### 케이스 B — 10만 원에 1억 투자 (실제 보유자 최다 구간)
- 100% 몰빵: 1억 → 3억 → 4,000만 → 1억 4천
- 80:20: 초기 8,000/2,000 → 20만: 매도 1,600 → 14,400/3,600 → 30만: 매도 1,400 → 총 **2억 5,200**(약식 20,000/5,000) → 12만: 매수 2,400 → 10,400/2,600(방송 중 오타 정정) → 8만: 매수 700 → 7,700/1,900 → 4만: 매수 700 → 4,600/1,200, 총 **5,800** → 16만: 매도 2,700 → 15,700/3,900 → 14만: 총 **1억 7,600**

### 케이스 C — 20만 원에 1억 투자 (고점 진입)
- 100% 몰빵: 1억 → 1억 5천 → 2,500만 → **7,000만 (여전히 −30%)**
- 80:20: 초기 8,000/2,000 → 30만: 매도 800 → 총 **1억 4천**(약식 11,000/3,000) → 12만: 매수 1,500 → 5,900/1,500 → 8만: 매수 400 → 4,400/1,100 → 4만: 매수 500 → 2,700/600, 총 **3,300** → 16만: 매도 1,700 → 9,100/2,300 → 14만: 총 **1억 300 (플러스 전환)**

### 종합 비교 (80:20 대비 몰빵, 수익률 차)
| 매수가 | 고점(30만) | 바닥(4만) | 현재(14만) |
|---|---|---|---|
| 2만 | −30% | **+20%** | **+4%** |
| 10만 | −16% | **+45%** | **+26%** |
| 20만 | −7% | **+32%** | **+47%** |

→ 고점에 인접해 살수록 현금 비중의 효과가 크다. 몰빵 C는 아직 −30%인데 80:20 C는 이미 +3%. "몰빵은 1억→15억→2억을 그냥 들고 견뎌야 하는데 그걸 버틸 사람은 없다."
