## 요지
배터리 원가 절감이라는 하나의 방향(셀투팩·46파이 규격화·건식 공정·전기차 전용 플랫폼)이 산업 표준을 바꾸고 있으며, 이 기술 전환에 올라탄 K배터리 셀사(LG엔솔)와 신공정 장비주(필에너지·피엔티)에 기회가 있다.

## 핵심 주장
- 셀→모듈→팩 구조는 쇼트·충격·온도로부터 셀을 보호하기 위한 것이지만, 모듈을 생략하는 셀투팩(CTP)이 무게·부피를 줄여 에너지 밀도와 주행거리를 높이는 방향으로 진화 중이다.
- 원통형·각형은 캔이 단단해 셀투팩이 쉽지만 파우치는 "라면 봉지"라 난이도가 높다 — 그 어려운 파우치형 셀투팩을 LG에너지솔루션이 세계 최초로 구현(2024-03-07 인터배터리 2024 공개)했다.
- 46파이 원통형은 셀 개수를 줄여 원가를 낮추는 게임 체인저로, 에너지 밀도 ~20% 향상 = 사실상 가격 ~20% 인하 효과. 90% 울트라하이니켈이 저니켈을 도태시키듯 2170에 머문 회사(파나소닉이 위기)는 도태된다.
- 원통형의 규격화(1865→2170→46파이)는 건전지처럼 벤더 교체를 가능하게 해 완성차의 공급망 다변화 무기가 되고, 협상력 약한 오토바이·자전거·킥보드 등 범용 수요도 원통형으로 흡수된다.
- 46파이의 기술적 관문은 열폭주 제어 → 탭리스(무지부 노칭) 공법이며, 여기서 레이저 노칭 장비(필에너지)라는 새 장비 수요가 생긴다.
- 4680의 두 번째 신공법은 건식 전극 공정 — NMP 건조 공정을 없애 에너지·시간·부지·부품 비용을 대폭 절감하지만 테슬라도 수율을 못 잡았고 LG엔솔 상용화 목표는 2028년(아직 방향성 단계).
- 2024년은 P(가격) 하락으로 셀·소재가 역성장하는 해지만 장비는 Q(수량)로 먹고살아 실적이 좋다 — 실적은 개선됐는데 주가는 같이 빠진 장비주(피엔티 예상 PER 8.3)가 좋은 매수 자리다.
- 원통형은 표준품이라 재고 생산·단독 공장이 가능하고(파우치는 모델 전용이라 합작 형태), LG엔솔 46시리즈는 테슬라·벤츠·리비안 3사를 이미 확보해 내년 성장 동력이 된다.
- 전기차 전용 플랫폼(E-GMP·MEB·얼티엄·스케이트보드)의 완성도가 전기차 상품력을 결정하며, 보유 4사는 현대차·테슬라·폭스바겐·GM — 그중 GM이 현대차를 찾아와 공동 개발을 발표(9/10)한 것은 긍정적 신호다.

## 방법론 — 교재① 재료
**1) 장비주 밸류에이션 절차 (피엔티 케이스에서 일반화)**
1. 올해 예상 영업이익 추정 (반기 실적 × 성장률로 연환산)
2. 세후 순이익 ≈ 영업이익 × 80% (법인세 약 20% 차감)
3. PER = 시가총액 ÷ 세후 순이익 → 예: 1조 ÷ 1,200억 ≈ 8.3배
4. 적정 PER 부여: 장비주는 증설 종료 후 매출 절벽 리스크로 소재 대비 디스카운트하되, 미국 전기차 침투율이 ~10%에 불과해 증설이 지속되므로 PER 25 수준까지 인정 가능
5. 업사이드 = 적정 PER ÷ 현재 PER + 이익 성장분 (3년 뒤 영업이익 2,000~3,000억이면 현 PER 4 수준 → 25 회복 시 ~6배)

**2) 사이클 국면별 밸류체인 포지셔닝**
- P(판가) 하락기: 광물 > 양극재 > 셀 순으로 타격 크고, 장비는 Q(발주 물량)로 실적 방어 → 다운사이클에는 실적 대비 같이 빠진 장비주를 노린다.
- 업턴 전환기: 리튬→양극재→셀 가격 상승의 P 레버리지는 소재·셀이 크므로 국면에 따라 갈아탄다.

**3) 기술 표준 전환 체크리스트**
- 신규 표준(46파이·탭리스·건식)이 원가를 낮추면 구세대(2170·습식)는 도태 → 각 밸류체인 회사가 신규격 대응 기술을 보유했는지로 생존 여부를 판별.
- "기술 방향성 제시"와 "실제 구현"을 구분할 것 — 건식 공정은 테슬라가 방향을 제시했을 뿐 수율 미확보, 상용화는 2028년 목표.
- 마더 팩토리(오창)에 장비 매출이 확인되면 해외 대량 증설 시 5~10배 매출로 이어질 수 있다는 선행 신호로 읽는다.
- 수주 뉴스로 급등 후 원위치한 종목은 펀더멘털 대비 눌린 자리인지 재점검 (피엔티: 테슬라 수주로 89,500원 급등 후 급락).

## 데이터·기술 — 교재② 재료
**배터리 팩 구조와 셀투팩(Cell-to-Pack)**

| 구조 | 구성 | 셀 개수 (테슬라 기준) |
|---|---|---|
| 기존 셀→모듈→팩 (2170) | 모듈이 보호막, 팩에 BMS | 팩당 ~4,300개 (모듈 ~430개 × 10모듈) |
| 셀투팩 (4680) | 모듈 생략, 셀이 팩에 직결 | 팩당 ~900개 |

- 모듈의 존재 이유: 셀 하나 쇼트(양극-음극 접촉 불량) 시 전체 전이 차단 + 외부 충격·온도 보호.
- 셀투팩 효과: 모듈 케이스 무게·부피 제거 → 에너지 밀도↑ → 주행거리↑, 부품·공정 감소 → 제조원가↓.
- 폼팩터별 난이도: 원통형(니켈도금 강판 캔)·각형은 자체 강성이 있어 쉬움, 파우치는 연포장재라 어려움 → LG엔솔이 팩 강성 보강 + 검증된 열전이 방지 기술로 파우치형 셀투팩 구현.

**원통형 규격 명명법**
- 18650 = 지름 18mm × 높이 65mm, 끝 "0" = 원통형 표시. 일론 머스크 제안으로 "당연히 원통형"이라며 0 생략 → 1865, 2170, 4680 표기로 정착.
- 46파이는 높이 표준 미확정: 4680 / 4695 / 46120 등 다양한 높이 테스트 중 (금양 측은 4680보다 95·120이 효율적이라는 입장).

**46파이의 장점과 기술 관문**

| 항목 | 수치/내용 |
|---|---|
| 에너지 밀도 | 기존 원통형 대비 ~20% 향상 (≈ 가격 20% 인하 효과) |
| 생산 속도 | 각형 대비 ~5배 |
| 원가 | 차 1대당 셀 개수 감소 → 원가 절감이 핵심 목적 |
| 기술 관문 | 지름이 커지면 중심부 열 배출이 지연 → 열폭주 위험 → 탭리스 공법 필수 |

**탭리스(Tabless) 공법**
- 기존 탭 = 전자의 유일한 통로("2차선 고속도로 정체") → 충방전 시 열 집중 → 폭발 위험.
- 탭리스 = 전극에 ㄷ자 무지부(활물질 미도포부)를 일정 간격 노칭 → 권취(와인딩)하면 젤리롤 전 단면으로 전자·열이 분산 배출.
- 노칭 방식: 금형(프레스) 노칭 대비 레이저 노칭이 정밀하고 비산물(흄, 셀 효율 저하 물질)이 없어 대세 → 레이저 노칭 장비 수요 발생.

**전극 공정과 건식 전극**
- 전극 공정 순서: 믹싱 → 코팅 → 건조 → 롤프레싱 → 슬리팅 → 노칭.
- 습식: NMP 용매로 슬러리를 만들어 집전체(양극 알루미늄박, 음극 동박)에 도포 후 건조. NMP는 유해물질로 회수·처리 필요.

| 습식의 비용 | 건식 전환 시 효과 |
|---|---|
| 건조가 공정 전체 에너지의 ~15% | 에너지 비용 ~30% 절감 |
| 건조가 공정 시간의 ~50% | 건조 설비 면적 ~50% 절감 |
| NMP 회수·처리 비용 | 공정 단순화로 부품 비용 ~20% 절감 |
| — | 코팅 두께 증대 가능 → 에너지 밀도↑, LFP보다 저렴해질 잠재력 |

- 트레이드오프: 건식은 점착성이 없어 "끈적이지 않는 잼을 빵에 바르는" 기술적 난제 → 테슬라 수율 미확보, LG엔솔 도입 연기(4분기 파일럿 라인, 2028년 상용화 목표), 파나소닉·CATL도 개발 중. 관련 기업: LG엔솔, 피엔티, 씨아이에스, 윤성에프앤씨, 하나기술 (그로스리서치 선정).

**46파이 양산 스케줄·수주**
- LG엔솔(9/5 발표): 국내 최초 하반기 46파이 양산, 오창 마더 팩토리에 5,800억 투자 → 검증 후 미국 애리조나 등 해외 대량 복제. 고객: 테슬라 → 메르세데스-벤츠 → 리비안(3사 확보).
- 리비안 R2: 4695 채택, LG엔솔이 5년간 67GWh 공급 ≈ 약 20조 원 (연 ~4조, LG엔솔 2023년 매출 ~33조의 10%+ 추가).
- 삼성SDI: GM과 미국 합작(얼티엄 1·2·3공장에 이은 4번째), 각형 우선 + 46파이 전환 논의 중. LG엔솔 46시리즈 증설용 장비 발주 개시(PO 완료) → 장비주 수혜.
- 사업모델 차이: 원통형=표준품이라 재고 생산·즉시 공급·단독 공장 가능 / 파우치=차종 전용이라 합작(JV) 형태.

**전기차 전용 플랫폼**
- 구조 차이: 내연기관(엔진→변속기→구동축, 부품 많고 복잡) vs 전기차(모터→감속기→바퀴, 단순 + 배터리 비중 큼) → 전용 골조(플랫폼) 필요, 개발비 수조 원.
- 플랫폼 하나로 소형~대형·SUV까지 커버 → 표준화·공간 효율·원가 절감. 저중심 배터리 배치로 코너링·승차감 개선.

| 회사 | 플랫폼 | 특징 |
|---|---|---|
| 현대차그룹 | E-GMP (2021) | 모듈식 배치, 800V 초고속 충전, ICCU 기반 V2L/V2V. 아이오닉5·6, EV3~EV9 |
| 현대차그룹 | EM·ES (차세대, 내년 목표) | EM: 전 세그먼트, 아이오닉5 대비 주행거리 +50%, 레벨3 자율주행, 전 차종 OTA / ES: 목적기반(배송·포터 후속) |
| 폭스바겐 | MEB (2018) → PPE → SSP (2026 예정) | MEB는 최초급이나 구형(800V·V2L 없음), PPE는 포르쉐 마칸 EV·아우디 A6 e-tron, SSP로 통합 예정 |
| GM | BEV-1 (1996, EV1) → BEV-2 (쉐보레 볼트) → BEV-3 (2020) → 얼티엄 | LG엔솔 공동 개발, 셀 4·8·16개 단위 조합으로 소형~허머 EV·캐딜락 리릭까지 |
| 테슬라 | 스케이트보드 (모델 S~) | 로드스터의 후면 배터리 → 바닥 평면 배치로 전환한 원조 |

- ICCU(Integrated Charging Control Unit): 고전압·12V 저전압 배터리 통합 충전 + 양방향 전력 변환 → V2L(외부 가전에 110/220V 공급)·V2V(차간 충전). EV9 90kWh ≈ 4인 가구 약 1주일 사용량 — 기아 슈퍼볼 광고의 핵심 소구점.
- 현대차 2030 목표(2021 대비): 배터리 에너지 밀도 +50%·원가 -40%, 모터 원가 -35%·중량 -30%.
- 전용 플랫폼 보유 완성차는 현대차·테슬라·폭스바겐·GM 4사뿐이며, GM-현대차 포괄 협력 발표(9/10)로 개발비 분담·공동 생산 가능성.

## 케이스 데이터
**필에너지 (레이저 노칭·스태킹 장비, 필옵틱스 자회사·2020년 물적분할)**
- 매출 추이: 2020년 174억 → 2021년 1,651억 → 2022년 1,897억 → 2023년 1,967억.
- 2024년: 1Q 573억 + 2Q 942억 = 상반기 1,515억(전년 동기 +26%) + 3Q 577억 → 3분기 누적 ~2,092억으로 이미 작년 연간 매출 초과. 영업이익도 분기 흑자 기조 유지, 연간 이익(32억→105억→153억 추이)보다 늘어날 여지.
- 2021년 레이저 노칭 장비 첫 납품 → 2022년 스태킹 통합 장비 → 2세대 통합 장비 프로모션 중. 46파이용 권취기(와인더)도 개발. 리스크: 지난 7월 유럽 배터리사(노스볼트 추정) 수주는 부실화 가능성.

**피엔티 (롤투롤 전극 공정 장비 — 강사가 꼽는 장비 대장주)**
- 밸류에이션 계산 (강의 실연): 올해 예상 영업이익 ~1,500억 × 0.8 = 세후 순이익 ~1,200억. 시가총액 ~1조(주가 42,450원 기준) ÷ 1,200억 = **PER 8.3**. 적정 PER 25 부여 시 ~3배, 3년 뒤 영업이익 2,000~3,000억이면 PER 4 수준 → 최대 ~6배 업사이드 논리.
- 매출: 2021년 3,777억 → 2022년 4,178억 → 2023년 5,432억 → 올해 ~80% 성장 페이스(매출 성장 ~80%, 영업이익 ~2배). 영업이익률 15%+.
- 수주잔고 ~2조 (2차전지 1.5조, 24년 1Q 기준). 국내 3사(LG엔솔·SK온·삼성SDI) 모두 납품하는 드문 장비사 + 테슬라 텍사스 건식 전극 장비 납품(기존 독일 장비 대체) — 경제적 해자.
- 주가: 테슬라 수주 공시로 89,500원까지 급등 후 원위치 → 실적 개선 미반영 구간이라는 판단.
