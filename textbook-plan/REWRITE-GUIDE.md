## Phase 1 — 목표 (4원칙)

1. **짧은 문단** — 링크드인처럼 쓱 읽히게. 한 문단 = 한 아이디어. 본문 문단 목표 중앙값 80~140자. 내용은 줄이지 말고 **문단만 쪼갠다**.
2. **스토리텔링(본론)** — 절마다 가능하면 `장면/오해 → 긴장 → 발견 → 규칙·이름`. 강의 비유(야프, 다리, 테드 등)는 축약하지 말고 서사로 유지. **장 오프닝을 소설로 새로 쓰지 말 것.**
3. **문어 어휘** — `값어치` → `가치` 전량. 과한 구어만 문어로. 강의 고유 비유 어휘는 보존.
4. **AI 티 제거** — 금지 목록·im-not-ai 패턴을 수술적으로 고친다. 사실·수치·인용은 不动.

## 절대 보존

- 논지, 수치, 날짜, 고유명사, 인용문(큰따옴표 안), 표 데이터
- `[[파일명|N장 제목]]` 위키링크, `<!-- MEDIA:... -->` 블록
- `## 직접 해보기`, `## 핵심 요약` 구조
- **기존 도입부의 논지·예고·위키링크** (Phase 1에서는 문단만 짧게 / 어휘만 다듬기)
- 강의에 없는 새 사실·새 사례를 만들지 말 것
- 분량: 원문 글자 수의 **85~115%**

전문어는 `_집필스타일`대로 **일상어 → 이름표** 순서.

## AI 티·어색 표현 금지

- `박아 넣는다` / `박혀 있다` / `박는다` (개념·숫자 맥락)
- `한 문장이 전부다`
- `핵심은 ~이다` / `중요한 것은 ~` / `바로 이것` / `다름 아니다`
- `본질적으로` / `핵심적으로` / `시사하는 바가 크다` / `주목할 만하다`
- `결론적으로` / `따라서` / `이를 통해` / `요약하면` / `정리하면` 남발
- 문두 `또한`·`나아가`·`아울러`·`게다가`·`더욱이`·`즉` 남발
- `~인 것이다` / `~다는 뜻이다` 결말 남발
- `먼저 · 반면 · 결국` 3단 공식 남발
- 과도한 `**볼드**` (절당 핵심 1~2곳만)
- `~에 대해` / `~를 통해` / `가지고 있다` 번역투
- 이중 피동 `~되어진다`

## 호흡·문단

- 200자 넘는 본문 문단은 원칙적으로 쪼갠다.
- 짧은 단정문을 홀로 두지 않는다. 무엇을·왜를 이어서 푼다.
- `→`·`·`로 문장을 잇는 전보문체 금지.
- 논증을 불릿으로 쪼개지 않는다. 불릿은 절차·체크리스트·핵심 요약에만.
- 헤더는 내용어 주장형 유지. `## 1.` 번호·4A 라벨 금지.

## Phase 1 작업 절차

1. 이 가이드의 **Phase 1**과 `교재/_집필스타일.md`를 읽는다.
2. 배정된 장 파일을 통째로 읽는다.
3. 같은 경로에 덮어쓴다.
4. **도입부를 소설 장면으로 교체하지 않았는지** 확인한다.
5. 자체검증: `값어치` 0, 수치·링크·표 보존, 분량 85~115%.
6. 부모 보고: 요지 5줄 + `값어치` 잔존 + 글자 수(원/개작).

## Phase 2 — 장 도입부 소설화 (나중에, 도입만)

Phase 1이 끝난 뒤, **H1 다음 ~ 첫 `##` 직전**만 다시 쓴다. 본론 금지.

### 목표
독자가 주인공인 장면으로 열되, **행동 나열표**가 되지 않게 쓴다.

### 금지 1 — 서술형 사건 설명
「주식시장 전체가 크게 떨어지는 날이 있다」처럼 밖에서 관찰하는 일반론.

### 금지 2 — 「뭐뭐 한다, 뭐뭐 한다」 행동 카탈로그
앱을 연다 → 스크롤한다 → 호가를 누른다 → 잠근다 → 다시 켠다처럼  
**동작만 짧게 나열하고 빠져나가는 문체**를 쓰지 않는다.

| 나쁜 예 (한다 한다) | 좋은 방향 |
|---|---|
| 스크롤을 내렸다 올린다. 호가를 눌러 본다. 일봉으로 간다. | 같은 숫자를 다른 화면에서 확인해도 마음이 가라앉지 않는 **한 가지 상태**를 깊게 |
| 수량을 입력했다가 지운다. 다시 넣었다가 지운다. | 수량 칸에 숫자가 들어갔을 때 드는 생각 한 줄 + 지우는 이유 한 줄 |

행동은 **감정을 드러내는 데 필요할 때만** 쓰고, 연속 동작 3개 이상을 문단마다 쌓지 않는다.  
장면의 중심은 “무엇을 했는가”가 아니라 **그때 어떤 기분·판단 공백에 빠졌는가**.

### 권장 골격
1. 장면 6~12문단 — 장소·감각·속마음 위주 (행동 나열 금지)
2. 공감 다리 — 「이런 경험이 한 번쯤 있었을 것이다」
3. 갈등·질문 → 장 예고 (기존 Phase 1 예고·링크 의미 보존)

### Phase 2 체크
- 동일 문단/인접 문단에 `~다. ~다. ~다.` 동작 종결이 3회 이상 반복되면 다시 쓴다.
- 가짜 종목명·가짜 구체 주가 금지.
- 첫 `##` 이후는 한 글자도 수정하지 않는다.
