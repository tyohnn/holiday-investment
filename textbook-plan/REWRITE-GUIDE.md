# 교재 1권 문체 개작 가이드

> 대상: `교재/교재1-방법론/*.md` (목차 제외, 장·부록 전량)
> 모델: cursor-grok-4.5-high-fast (장당 1 서브에이전트)
> 기준 문서: `교재/_집필스타일.md` + im-not-ai(humanize-korean) quick-rules
> 작법 모델: 『더 골』·『타이탄의 도구들』·『부의 추월차선』

## 목표 (4원칙)

1. **짧은 문단** — 링크드인처럼 쓱 읽히게. 한 문단 = 한 아이디어. 본문 문단 목표 중앙값 80~140자. 내용은 줄이지 말고 **문단만 쪼갠다**.
2. **스토리텔링** — 절마다 가능하면 `장면/오해 → 긴장 → 발견 → 규칙·이름` 순서. 강의 비유는 축약하지 말고 서사로 유지.
3. **문어 어휘** — `값어치` → `가치` 전량. 과한 구어만 문어로. 강의 고유 비유 어휘는 보존.
4. **AI 티 제거** — 아래 금지 목록·im-not-ai 패턴을 수술적으로 고친다. 사실·수치·인용은 不动.

## 절대 보존

- 논지, 수치, 날짜, 고유명사, 인용문(큰따옴표 안), 표 데이터
- `[[파일명|N장 제목]]` 위키링크, `<!-- MEDIA:... -->` 블록
- `## 직접 해보기`, `## 핵심 요약` 구조
- 강의에 없는 새 사실·새 사례를 만들지 말 것
- 분량: 원문 글자 수의 **85~115%** (내용 삭제 금지; 문단 분할은 OK)

## 어휘 치환 (필수)

| 금지/변경 전 | 변경 후 |
|---|---|
| 값어치 | 가치 |
| 싸 보이는 덫 | 가치의 함정 / 싸게 보이는 함정 (문맥에 맞게, 한 장 안에서는 통일) |

전문어는 `_집필스타일`대로 **일상어 → 이름표** 순서를 유지한다.

## AI 티·어색 표현 금지

다음이 보이면 고친다. 대체는 구체 서술로.

- `박아 넣는다` / `박혀 있다` / `박는다` (개념·숫자 맥락)
- `한 문장이 전부다`
- `핵심은 ~이다` / `중요한 것은 ~` / `바로 이것` / `다름 아니다`
- `본질적으로` / `핵심적으로` / `시사하는 바가 크다` / `주목할 만하다`
- `결론적으로` / `따라서` / `이를 통해` / `요약하면` / `정리하면` 남발
- 문두 `또한`·`나아가`·`아울러`·`게다가`·`더욱이`·`즉` 남발
- `~인 것이다` / `~다는 뜻이다` 결말 남발
- `먼저 · 반면 · 결국` 3단 공식 남발
- 과도한 `**볼드**` (절당 핵심 1~2곳만)
- `~에 대해` / `~를 통해` / `가지고 있다` 번역투
- 이중 피동 `~되어진다`

## 호흡·문단

- 200자 넘는 본문 문단은 원칙적으로 쪼갠다.
- 짧은 단정문을 홀로 두지 않는다. (`이 장은 그 선을 긋는다.` 금지) 무엇을·왜를 이어서 푼다.
- `→`·`·`로 문장을 잇는 전보문체 금지.
- 논증을 불릿으로 쪼개지 않는다. 불릿은 절차·체크리스트·핵심 요약에만.
- 헤더는 내용어 주장형 유지. `## 1.` 번호·4A 라벨 금지.

## 스토리텔링 (더 골식)

각 `##` 절에서:

1. 독자가 겪는 장면·오해로 연다 (이미 도입에 있으면 반복하지 말 것).
2. 왜 그게 문제인지 한두 문단.
3. 비유·사례로 “발견”을 보여 준다.
4. 그다음에야 규칙·용어·공식을 붙인다.

『타이탄의 도구들』처럼 한 절 = 한 아이디어.  
『부의 추월차선』처럼 문장은 짧고 단정하되, 과장 슬로건·훈계 말투는 쓰지 않는다.

## 장 도입부 — 소설형 장면 (필수)

H1 직후 **헤더 없는 도입**은 사건 설명이 아니라 **독자가 주인공인 짧은 소설 장면**으로 연다.

참고 작법:
- Josh Bernoff: 논픽션 장은 **이야기부터** 시작하고, 원칙은 그 다음에 둔다.
- scene-construction (skills.sh): **이미 벌어지는 한가운데**에서 연다 (mid-action). 배경 설명으로 열지 않는다.
- SCQA / 상황–전환–주제: 구체 상황 → 불편·갈등 → “왜?” → 이 장의 답.
- 2인칭·근접 시점: 출근길, 앱 화면, 손가락, 속마음처럼 **감각·행동·고민**을 보여 준다.

### 금지 (서술형 사건 설명)

```
주식시장 전체가 크게 떨어지는 날이 있다. 뉴스에서 "코스피 급락"이라고 부르는 그런 날이다.
이런 날, 같은 회사의 주식을 가지고 있던 두 사람이 정반대로 움직인다.
```

위처럼 **밖에서 관찰하는 설명**으로 시작하면 실패다. “~하는 날이 있다”, “~라고 부른다”, “두 사람이 있다” 식의 일반론 오프닝을 쓰지 않는다.

### 권장 골격 (4비트)

1. **장면** — 구체 시간과 행동. 예: 출근길에 습관처럼 주식 앱을 연다. 빨간 숫자, 보유 종목 −12%, 팔지 말지 손가락이 멈춘다.
2. **공감 다리** — “이런 경험이 한 번쯤 있었을 것이다.” / “아마 당신도…”
3. **갈등·질문** — 그 장면에서 진짜 문제는 무엇인지 (이 장이 답할 질문).
4. **예고** — 이 장에서 무엇을 배울지 한두 문단 (기존 `_집필스타일` 도입 규약 유지).

### 좋은 예 (톤만; 장마다 장면은 새로 쓸 것)

```
출근길에 습관처럼 주식 앱을 열었다.
어제까지 멀쩡하던 숫자가 온통 빨갛다. 제일 많이 넣어 둔 종목이 하루 만에 두 자리 퍼센트로 빠져 있다.

팔아야 하나. 아니면 더 사야 하나.
손가락이 매수와 매도 사이에서 멈춘다.

이런 경험이 한 번쯤 있었을 것이다.
같은 화면을 보고도 어떤 사람은 돈을 더 넣고, 어떤 사람은 손해를 확정한다.
차이는 배짱이 아니다. 애초에 서로 다른 게임을 하고 있었기 때문이다.
```

### 도입부 체크

- 첫 문장에 일반명사 정의·뉴스 요약·“~하는 날이 있다”가 오면 다시 쓴다.
- 첫 3~6문단 안에 **사람·행동·감각·속마음** 중 셋 이상이 있어야 한다.
- 장면은 2~5문단. 그 다음 공감 다리 → 장 질문 → 배울 내용 예고.
- 장면을 위해 **강의에 없는 가짜 수치·가짜 종목 실명**을 만들지 않는다. 종목이 필요하면 “제일 많이 넣어 둔 종목”처럼 익명으로.
- 본론의 야프섬·다리·테드 윌리엄스 등 **기존 비유 서사와 톤이 충돌하지 않게** 맞춘다.

## im-not-ai 자체검증 (개작 후)

1. 고유명사·수치·날짜·인용 100% 보존
2. 의미 변경 없이 문체만 손봤는가
3. `값어치` 잔존 0
4. 금지 표현 잔존을 파일 안에서 검색해 제거
5. 위키링크·MEDIA·표 깨짐 없음
6. 장르 이탈 없음 (교재 산문 유지; 블로그체·이모지·과한 구어 금지)

## 작업 절차 (서브에이전트)

1. 이 가이드와 `교재/_집필스타일.md`를 읽는다.
2. 배정된 장 파일을 **통째로** 읽는다.
3. 같은 경로에 개작본을 덮어쓴다 (새 파일 만들지 말 것).
4. 위 자체검증을 수행한다.
5. 부모에게 보고: 변경 요지 5줄 + `값어치` 잔존 수 + 대략 문단 수 변화 + 분량(원문/개작 글자 수).
