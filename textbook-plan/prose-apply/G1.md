# G1 문체 개작 계획

## 범위와 모드

- 대상은 `교재/교재1-방법론/G1-감정-배제-장치.md` 한 파일로 한정한다.
- 적용 모드는 `nonfiction + webnovel-breath + linkedin-scan + novel-opening + anti-patterns`다.
- 원문 12,791자의 85~115퍼센트인 10,873~14,709자 안에서 수술적으로 고친다.
- 새 사실·사례·대사·수치·투자 조언은 만들지 않는다.

## 장 약속

이 장을 읽으면 독자는 감정적 매매를 일으키는 편향을 알아보고, 현금 비중·분산·말·기록·정보 규칙으로 판단을 자동화할 수 있다.

## 수술 지점

1. 도입은 원문에 이미 있는 `침착한 계획표`와 `흔들리는 숫자`의 충돌로 바로 연다. 출근길·앱 조작·가짜 종목 장면은 보태지 않는다.
2. 추세 연장, 본전 기억, 고점의 안도감이 어떻게 반대 행동을 만드는지 `현상 → 긴장 → 이름 → 교정 규칙` 순서로 정돈한다.
3. 일곱 편향과 피터 린치의 열두 문장을 목록으로만 두지 않고, 문서화된 원칙과 절차 평가라는 하나의 처방으로 회수한다.
4. 심리적 회계와 닻 효과는 일상어로 먼저 설명한 뒤 개념 이름을 붙인다. 종목 단위 언어를 계좌 전체 언어로 바꾸는 이유를 앞세운다.
5. 에코프로 사이클과 삼성SDI 사례는 기존 수치와 결론을 그대로 두고, 사례가 입증하는 범위와 적용 장치를 더 선명하게 연결한다.

## 보존·검증 기준

- 모든 수치·날짜·고유명사·큰따옴표 인용·표 행과 셀을 보존한다.
- 위키링크와 `<!-- MEDIA -->`는 원문에 없다는 상태까지 포함해 그대로 유지한다.
- `## 직접 해보기`와 `## 핵심 요약`의 제목·기능·내용을 보존한다.
- 제목과 각 문단 첫 문장만 훑어도 `편향 → 장치 → 적용 → 사례`가 이어지게 한다.
- 짧은 단정문 고립, 연속 행동 나열, 강제 역설, 추상 은유, 바이럴 문구를 남기지 않는다.
