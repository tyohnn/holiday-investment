# H1 문체 개작 계획

- 대상: `교재/교재1-방법론/H1-현대차기아-삼양식품.md`
- 모드: `nonfiction + webnovel-breath + linkedin-scan + novel-opening + anti-patterns`
- 분량 목표: 원문 19,029자의 85~115%(16,175~21,883자)
- 장 약속: 이 장을 읽으면 독자는 실제 기업의 숫자로 가설을 세우고, 미리 정한 감시 지표가 가설을 반박할 때 계산과 결론을 갱신할 수 있다.

## 개작 원칙

1. 기록된 시점과 수치가 충돌하는 순간으로 도입을 재배열하되, 장면·대사·감정은 만들지 않는다.
2. 현대차·기아는 `체질 비교 → 아홉 칸 계산 → 1차 가설 → 반증 → 새 판정`의 발견 흐름을 선명하게 한다.
3. 삼양식품은 `공개 정보로 세운 이야기 → 동종 기업 비교 → 1차 계산 → 실적 반증 → 재계산`의 검증 흐름을 유지한다.
4. 긴 문단과 전보식 단문을 한 논리 단위씩 조정하고, 절의 첫 문장이 곧바로 정보나 판단을 전달하게 한다.
5. ‘핵심은’, ‘결정적으로’, ‘결론적으로’ 같은 선언형 연결어와 추상적 강조를 줄이고, 숫자와 인과가 스스로 결론을 만들게 한다.

## 절대 보존

- 모든 사실·수치·날짜·고유명사·인용문과 표 데이터
- 기존 링크와 `<!-- MEDIA -->` 블록
- `## 직접 해보기`, `## 핵심 요약`의 제목·기능·내용
- 현대차·기아와 삼양식품의 투자 판정 및 판정이 나온 시점
- 원문에 없는 현장, 행동, 대사, 표정, 날씨, 내면을 추가하지 않는다.

## 검증

- 글자 수를 원문과 비교해 85~115% 범위인지 확인한다.
- 표 행과 표 셀, 숫자 토큰, 링크, 보존 헤더를 원문과 대조한다.
- `값어치`, 금지 관용구, 과도한 선언형 연결어, 220자 초과 본문 문단을 점검한다.
- `bash`나 코드 파일은 건드리지 않고 대상 장과 이 계획서만 변경된 상태인지 확인한다.
